RULE 1: When Machine mode executes csrr x10, satp as a SATP read, the instruction succeeds without exception and writes the SATP value to x10.
RULE 10: When Supervisor mode executes csrr x10, satp as a SATP read, the instruction succeeds without exception and writes the SATP value to x10.
RULE 28: When User mode executes csrr x10, satp as a SATP read, the access traps with an illegal instruction exception and SATP is not read or written normally.
RULE 50: When Machine mode executes csrw satp, x10 and writes 0x0000000000000001 to SATP, the write is accepted without exception and SATP reflects 0x0000000000000001.
RULE 52: When Machine mode executes csrw satp, x10 and writes 0x0000100000000000 to SATP, the write is accepted without exception and SATP reflects 0x0000100000000000.
RULE 53: When Machine mode executes csrw satp, x10 and writes 0x1000000000000000 to SATP while the old SATP value is 0x0000000000000000, the write preserves the old SATP value without exception.
RULE 60: When Machine mode executes csrw satp, x10 and writes 0xffffffffffffffff to SATP while the old SATP value is 0x0000000000000000, the write preserves the old SATP value without exception.
