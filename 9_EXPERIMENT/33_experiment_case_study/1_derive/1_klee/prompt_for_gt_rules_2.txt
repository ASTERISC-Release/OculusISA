You are comparing a generated RISC-V architectural rule set against a ground truth rule set.

Target name:
{target_name}

Generated rules:
{generated_rules_text}

Ground truth rules:
{ground_truth_rules_text}

Task:
Determine which ground truth rules are covered by the generated rules using one-to-one matching.

A generated rule covers a ground truth rule only if it clearly expresses the same architectural behavior, or a behavior that fully includes the ground truth rule's required condition and outcome.

Important requirements:

1. Use only the given generated rules and ground truth rules.
2. Do not use external knowledge.
3. Do not use known bugs.
4. Do not infer behavior that is not explicitly stated.
5. Be conservative and precise.
6. Do not count a ground truth rule as covered if the generated rule only partially matches it.
7. Use one-to-one matching only.
8. Each generated rule may cover at most one ground truth rule.
9. Each ground truth rule may be covered by at most one generated rule.
10. Do not allow one generated rule to cover multiple ground truth rules.
11. Do not allow multiple generated rules to cover the same ground truth rule.
12. If multiple generated rules could cover the same ground truth rule, choose the best semantic match.
13. If one generated rule could cover multiple ground truth rules, choose the best semantic match.
14. If there is a tie, choose the match that maximizes the total number of covered ground truth rules.
15. If there is still a tie, choose the lowest generated rule number.
16. If there is still a tie, choose the lowest ground truth rule number.
17. Duplicate generated rules do not increase coverage; only one duplicate may be matched.
18. Use only rule numbers that appear in the input.

Output two text files.

First file name:
coverage_summary.txt

The first file must use this format:

COVERAGE SUMMARY
Covered ground truth rules: X / Y
Coverage: Z%

COVERED GT RULES
GT RULE 1 -> covered by GENERATED RULE 4
GT RULE 2 -> covered by GENERATED RULE 9
GT RULE 3 -> NOT COVERED

UNCOVERED GT RULES
GT RULE 3
GT RULE 8
GT RULE 10

Second file name:
generated_rule_to_gt_mapping.txt

The second file must use this format:

GENERATED RULE TO GROUND TRUTH MAPPING
GENERATED RULE 1 -> GT RULE 69
GENERATED RULE 2 -> -
GENERATED RULE 3 -> GT RULE 1

Rules:

* Use "-" when a generated rule does not cover any ground truth rule.
* Keep generated rules in numeric order.
* Keep ground truth rules in numeric order.
* Do not add extra explanations unless needed for ambiguity.
* Do not include any rule number that is not present in the input.
* The mapping must be one-to-one: no generated rule may appear with more than one GT rule, and no GT rule may appear with more than one generated rule.
