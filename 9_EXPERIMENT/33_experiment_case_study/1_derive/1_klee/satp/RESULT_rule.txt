RULE 1: Virtualized SATP access with hstatus.VTVM set raises a virtual instruction exception; no SATP or VSATP write occurs and no TLB flush occurs.
RULE 2: Non virtual SATP access with mstatus.TVM set below M privilege raises an illegal instruction exception; no SATP write occurs and no TLB flush occurs.
RULE 416: When Access is virtualized, so CSR satp is routed to VSATP, hstatus.VTVM = 1, The access traps before the ATP value is updated, and Write value, old ATP value, ASID mask, PPN mask, and MMU availability are not used after this permission failure, the access raises a virtual instruction exception, is routed to VSATP, does not update SATP or VSATP, and does not flush the TLB.
RULE 620: When Access is non virtual, so CSR satp targets SATP, mstatus.TVM = 1, Effective privilege = S, which is below M in this path, The access traps before the SATP value is updated, and Write value, old SATP value, ASID mask, PPN mask, and MMU availability are not used after this permission failure, the access raises an illegal instruction exception, is routed to SATP, does not update SATP or VSATP, and does not flush the TLB.
