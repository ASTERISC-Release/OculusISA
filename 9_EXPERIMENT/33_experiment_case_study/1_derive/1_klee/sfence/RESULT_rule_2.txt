RULE 3: When SFENCE.VMA is executed in non-virtual mode with S extension present, an MMU present, mstatus.TVM clear, and current privilege U, it raises an illegal instruction exception and does not flush the TLB.
RULE 4: When the S extension is implemented, an MMU is present, execution is in non-virtual mode, mstatus.TVM is clear, and the current privilege mode is S mode or M mode, executing SFENCE.VMA completes without exception and flushes the TLB.
RULE 5: In non-virtual mode, when the S extension and MMU are present and mstatus.TVM is set, executing SFENCE.VMA in U or S privilege raises an illegal instruction exception and does not flush the TLB.
RULE 7: When SFENCE.VMA is executed in virtual mode with the S extension present, an MMU present, and current privilege mode U, a virtual instruction exception is raised and no TLB flush is performed.
RULE 9: When SFENCE.VMA is executed in virtual mode with ext_s = 1, has_mmu = 1, privilege mode S or M, and hstatus.VTVM = 1, a virtual instruction exception is raised and no TLB flush is performed.
