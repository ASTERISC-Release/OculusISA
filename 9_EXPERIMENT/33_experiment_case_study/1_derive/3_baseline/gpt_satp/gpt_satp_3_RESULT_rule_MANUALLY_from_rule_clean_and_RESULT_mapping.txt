RULE 2: If the current privilege mode is U-mode and an instruction attempts to read satp, then an illegal-instruction exception is raised.
RULE 10: If the current privilege mode is M-mode and an instruction reads satp, then the read returns the current architectural value of satp.
RULE 18: If an instruction writes satp with an unsupported MODE value, then no field of satp is modified.
RULE 22: If satp.MODE=Bare and satp is active for a memory access, then the virtual address of that access is used as the physical address for purposes of satp address translation.
RULE 41: If ASIDLEN=N and N>0, then writes to satp.ASID[N-1:0] are retained according to the written value.
