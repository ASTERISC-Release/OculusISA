RULE 1: If a CSR instruction attempts to access scounteren while the current privilege mode is U-mode, the instruction raises an illegal-instruction exception.
RULE 2: If a CSR instruction attempts to access scounteren while the current privilege mode is S-mode, the access is not rejected due to insufficient privilege for scounteren.
RULE 3: If a CSR instruction attempts to access scounteren while the current privilege mode is M-mode, the access is not rejected due to insufficient privilege for scounteren.
RULE 140: If a bit in scounteren is zero, the corresponding U-mode counter CSR read trap is reported as an illegal-instruction exception.
