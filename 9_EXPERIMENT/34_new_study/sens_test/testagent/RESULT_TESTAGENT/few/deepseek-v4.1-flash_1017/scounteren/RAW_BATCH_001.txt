# Test Case Rule: RULE 1: The scounteren register has a privilege of SRW.
##### ASSEMBLY #####
call machine_to_supervisor
li a0, 0
li t0, 1
csrw 0x106, t0
csrr a1, 0x106
li a0, 1
# Result: a0 = 1

# Test Case Rule: RULE 2: When the CY, TM, IR, or HPM n bit in the scounteren register is clear, attempts to read the cycle, time, instret, or hpmcountern register while executing in U-mode will cause an illegal-instruction exception.
##### ASSEMBLY #####
li t0, 1
csrw 0x306, t0
csrw 0x106, x0
call machine_to_user
csrr a0, 0xc00
# Result: mcause = 0x2

# Test Case Rule: RULE 3: When one of the CY, TM, IR, or HPM n bits in the scounteren register is set, access to the corresponding register is permitted.
##### ASSEMBLY #####
li t0, 1
csrw 0x306, t0
csrw 0x106, t0
call machine_to_user
li a0, 0
csrr a1, 0xc00
li a0, 1
# Result: a0 = 1

# Test Case Rule: RULE 4: U-mode may only access a counter if the corresponding bits in scounteren and mcounteren are both set.
##### ASSEMBLY #####
li t0, 1
csrw 0x106, t0
csrw 0x306, x0
call machine_to_user
csrr a0, 0xc00
# Result: mcause = 0x2

# Test Case Rule: RULE 5: In VU-mode, a counter is not readable unless the applicable bits are set in both hcounteren and scounteren.
##### ASSEMBLY #####
li t0, 1
csrw 0x306, t0
csrw 0x606, t0
call machine_to_virtual
li t0, 1
csrw 0x106, t0
call vs_to_vu
li a0, 0
csrr a1, 0xc00
li a0, 1
# Result: a0 = 1

# Test Case Rule: RULE 6: When V=1, a virtual-instruction exception (code 22) is normally raised instead of an illegal-instruction exception if the attempted instruction is HS-qualified, which means it would be valid to execute in HS-mode assuming fields TSR and TVM of CSR mstatus are both zero, but is prevented from executing when V=1 either due to insufficient privilege or because the instruction is expressly disabled by a supervisor CSR such as scounteren.
##### ASSEMBLY #####
call machine_to_virtual_user
csrr a0, 0x106
