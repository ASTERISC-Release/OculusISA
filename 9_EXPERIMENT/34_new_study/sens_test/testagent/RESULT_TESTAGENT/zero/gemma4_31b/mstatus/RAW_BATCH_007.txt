# Test Case Rule: RULE 121: In harts without additional user extensions requiring new state, the XS field in mstatus is read-only zero.
##### ASSEMBLY #####
li t0, 3
csrrw sp, mstatus, t0
csrr t1, mstatus
li t2, 0x1800 # XS is bits 13:12 for RV64 (depending on spec version, usually 13:12)
srli t1, t1, 12
and t1, t1, 3
# Result: t1 = 0

# Test Case Rule: RULE 122: Changing the setting of the FS field in mstatus has no effect on the contents of the floating-point register state.
##### ASSEMBLY #####
flw f0, 0(zero) # Arbitrary load to set state
li t0, 0
srli t1, t0, 13 # Shift to FS position
csrrw sp, mstatus, t1 # Set FS to Off
flw f1, 0(zero) # Trigger something to ensure it doesnt crash if we just want to check f0
# Result: f0 = f0

# Test Case Rule: RULE 123: Setting the FS field in mstatus to Off does not destroy the floating-point state, and setting the FS field to Initial does not clear the floating-point contents.
