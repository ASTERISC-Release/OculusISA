# Test Case Rule: RULE 1: The satp register has the privilege SRW.
##### ASSEMBLY #####
li x10, 0x1000000000000000
csrrw satp, x10
# Result: satp is supervisor read/write

# Test Case Rule: RULE 2: Unless otherwise specified, the value returned by an implicit read of the satp CSR is the same value that would have been returned by an explicit read of the satp CSR, using a CSR-access instruction in a sufficient privilege mode.
##### ASSEMBLY #####
csrrw t0, satp
csrrw t1, satp
# Result: t0 = t1

# Test Case Rule: RULE 3: If S-mode is not supported or satp.MODE is read-only 0, the SUM (permit Supervisor User Memory access) bit is read-only 0.

# Result: sstatus[1] = 0
