REGISTER: mseccfg
SUMMARY: The mseccfg register manages security configurations for seed CSR access, memory locking, and forward-edge CFI via the Zicfilp extension. It uses the USEED and SSEED fields to regulate read-write access to the seed CSR in U and S/HS modes, with unauthorized access triggering an illegal-instruction exception. The MML, MMWP, and RLB fields configure memory locking behaviors, where MML defines specific access restrictions—such as inaccessible, locked shared code, or locked read-only regions—based on pmpcfg settings. Access to the register is restricted to M-mode, while S and U-mode access attempts result in illegal-instruction exceptions.

REGISTER: mstatus
SUMMARY: The mstatus register manages processor status, interrupt states, and privilege levels, with access restricted to M-mode to prevent unauthorized modifications from S or U modes. It facilitates trap handling and privilege transitions by recording previous modes and interrupt-enable states, which are used to determine return privilege levels and trap behaviors. The register also defines memory access characteristics, including endianness, privilege-based protection, and virtualization-aware memory behavior. Finally, it tracks the status of floating-point, vector, and other extensions, triggering illegal-instruction exceptions when instructions attempt to access state or execute while these units are disabled.

REGISTER: satp
SUMMARY: The satp register manages address translation and memory protection through fields defining translation modes, physical page numbers (PPN), and address space identifiers (ASID). It supports various configurations, such as Sv48 page-based addressing and Bare mode, where supervisor virtual addresses are equivalent to physical addresses. Access is strictly governed by privilege levels, with U-mode access triggering an illegal-instruction exception and S-mode access being contingent on the TVM bit. The register ensures integrity by ignoring writes to unsupported modes and exhibiting specific readback behaviors for mode fields when accessed in M-mode.

REGISTER: scounteren
SUMMARY: The scounteren register controls access permissions for hardware counters such as cycle, time, instret, and hpmcountern, with specific control bits for CY, TM, IR, and HPM4–HPM18. U-mode access to these counters is permitted only when the corresponding bits in both scounteren and mcounteren are set. While M-mode and HS-mode have unrestricted access to the scounteren register, U-mode access triggers an illegal-instruction exception. Additionally, the register is inaccessible to any privilege level lower than SRW.
