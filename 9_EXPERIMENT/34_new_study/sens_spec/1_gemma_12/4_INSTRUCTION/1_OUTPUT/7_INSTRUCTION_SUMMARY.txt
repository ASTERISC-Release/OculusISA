INSTRUCTION: CSRRWI
SUMMARY: The CSRRWI instruction updates a CSR using an XLEN-bit value derived from a zero-extended 5-bit unsigned immediate in the rs1 field. The instruction always performs a CSR write, but it only executes a CSR read and associated side effects if the destination register rd is not x0. If rd is x0, the instruction performs the write without any read operations or read-related side effects. The architectural state must reflect the expected side effects of the written CSR fields.

INSTRUCTION: FCVT.W.D
SUMMARY: FCVT.W.D converts a double-precision floating-point number from register rs1 into a signed 32-bit integer in register rd. The operation applies rounding to the resulting integer based on the specified rm field.

INSTRUCTION: SFENCE.VMA
SUMMARY: The SFENCE.VMA instruction uses register rs1 to specify a virtual address. Execution is permitted in S-mode when the TVM bit is 0, while an attempt to execute in U-mode triggers an illegal-instruction exception. In VS-mode, the instruction raises a virtual-instruction exception if the VTVM bit is 1. No exceptions are raised for invalid addresses in rs1 or during speculative execution.

INSTRUCTION: VLE32FF.V
SUMMARY: The VLE32FF.V instruction loads data into a destination vector register, with its operation scope governed by the vector length (vl) and start index (vstart). Synchronous exceptions at element 0 trigger a trap without modifying the vector length, while exceptions at indices greater than 0 reduce the vector length to that index unless they are debug watchpoint traps or interrupts. For interrupts, the vstart value is updated, while for both interrupts and debug traps, the vector length is preserved. If a trap or trimming occurs at index $i$, destination elements beyond $i$ may be overwritten with indeterminate values while elements beyond the original vector length are protected during faults, and a restart may leave non-idempotent memory in a modified state.
