RULE 1: When mstatus.VS is set to Off, any attempt to execute a vector instruction or access a vector CSR shall raise an illegal-instruction exception.
RULE 2: When mstatus.VS is set to Initial or Clean, executing any instruction that changes vector state, including vector CSRs, shall change mstatus.VS to Dirty.
RULE 3: If mstatus.VS is Dirty, mstatus.SD shall be 1.
RULE 4: When the hypervisor extension is present and V=1, an attempt to execute any vector instruction or access vector CSRs shall raise an illegal-instruction exception if either mstatus.VS or vsstatus.VS is set to Off.
RULE 5: When the hypervisor extension is present, V=1, and neither vsstatus.VS nor mstatus.VS is set to Off, executing any instruction that changes vector state, including vector CSRs, shall change both mstatus.VS and vsstatus.VS to Dirty.
