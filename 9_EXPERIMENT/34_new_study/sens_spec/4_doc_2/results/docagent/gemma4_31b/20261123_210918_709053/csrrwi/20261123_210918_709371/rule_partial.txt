RULE 1: CSRRWI atomically reads the value of the specified CSR, zero-extends the value to XLEN bits, and writes it to integer register rd.
RULE 2: CSRRWI updates the specified CSR using an XLEN-bit value obtained by zero-extending a 5-bit unsigned immediate (uimm[4:0]) field.
RULE 3: If rd = x0 for a CSRRWI instruction, the instruction shall not read the CSR and shall not cause any of the side effects that might occur on a CSR read.
RULE 4: A CSRRWI instruction always writes to the specified CSR.
RULE 5: CSRRWI action side effects for all fields within the written CSR.
RULE 6: The CSRRWI instruction carries a dependency from the CSR to the destination register rd.
RULE 7: If the destination register rd is not x0, the CSRRWI instruction writes the original value of the CSR to rd.
RULE 8: The CSRRWI instruction writes an immediate value to the CSR.
