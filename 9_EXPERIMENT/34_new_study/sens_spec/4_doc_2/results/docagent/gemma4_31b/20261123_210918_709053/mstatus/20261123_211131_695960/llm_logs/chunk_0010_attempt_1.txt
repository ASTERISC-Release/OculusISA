RULE 1: If mstatus.FS is Off, any attempt to execute a vector floating-point instruction shall raise an illegal-instruction exception.
RULE 2: Any vector floating-point instruction that modifies floating-point extension state, such as floating-point CSRs or f registers, shall set mstatus.FS to Dirty.
RULE 3: If the hypervisor extension is implemented and V=1, and either vsstatus.FS or mstatus.FS is Off, any attempt to execute a vector floating-point instruction shall raise an illegal-instruction exception.
RULE 4: If the hypervisor extension is implemented and V=1, any vector floating-point instruction that modifies floating-point extension state, such as floating-point CSRs or f registers, shall set both mstatus.FS and vsstatus.FS to Dirty.
