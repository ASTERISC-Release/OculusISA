RULE 1: FCVT.W.D converts a double-precision floating-point number in floating-point register rs1 to a signed 32-bit integer in integer register rd.
RULE 2: FCVT.W.D rounds the result according to the rm field.
RULE 3: If XLEN > 32, FCVT.W.D sign-extends the 32-bit result to the destination register width.
RULE 4: If the rounded result of FCVT.W.D is not representable in the destination format, the result is clipped to the nearest value and the invalid flag is set.
RULE 5: If the rounded result of FCVT.W.D is an out-of-range negative input, the output is -2^31.
RULE 6: If the rounded result of FCVT.W.D is -∞, the output is -2^31.
RULE 7: If the rounded result of FCVT.W.D is an out-of-range positive input, the output is 2^31 - 1.
RULE 8: If the rounded result of FCVT.W.D is +∞ or NaN, the output is 2^31 - 1.
RULE 9: FCVT.W.D sets the Inexact exception flag if the rounded result differs from the operand value and the Invalid exception flag is not set.
RULE 10: If the input operand for FCVT.W.D is a narrower n-bit value (n < FLEN), FCVT.W.D treats the input as an n-bit canonical NaN if the upper FLEN-n bits are not all 1s.
RULE 11: If the input operand for FCVT.W.D is a narrower n-bit value (n < FLEN) and the upper FLEN-n bits are all 1s, FCVT.W.D uses the n least-significant bits as the input value.
