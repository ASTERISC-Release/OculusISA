RULE 1: If `mseccfg.MML` is set to 1, a PMP entry with `L=0, R=0, W=0, X=0` results in an inaccessible region causing an access exception for both M-mode and S/U-mode.
RULE 2: If `mseccfg.MML` is set to 1, a PMP entry with `L=0, R=0, W=0, X=1` results in an access exception for M-mode and an execute-only region for S/U-mode.
RULE 3: If `mseccfg.MML` is set to 1, a PMP entry with `L=0, R=0, W=1, X=0` results in a shared data region that is read/write for M-mode and read-only for S/U-mode.
RULE 4: If `mseccfg.MML` is set to 1, a PMP entry with `L=0, R=0, W=1, X=1` results in a shared data region that is read/write for both M-mode and S/U-mode.
RULE 5: If `mseccfg.MML` is set to 1, a PMP entry with `L=0, R=1, W=0, X=0` results in an access exception for M-mode and a read-only region for S/U-mode.
RULE 6: If `mseccfg.MML` is set to 1, a PMP entry with `L=0, R=1, W=0, X=1` results in an access exception for M-mode and a read/execute region for S/U-mode.
RULE 7: If `mseccfg.MML` is set to 1, a PMP entry with `L=0, R=1, W=1, X=0` results in an access exception for M-mode and a read/write region for S/U-mode.
RULE 8: If `mseccfg.MML` is set to 1, a PMP entry with `L=0, R=1, W=1, X=1` results in an access exception for M-mode and a read/write/execute region for S/U-mode.
RULE 9: If `mseccfg.MML` is set to 1, a PMP entry with `L=1, R=0, W=0, X=0` results in a locked inaccessible region causing an access exception for both M-mode and S/U-mode.
RULE 10: If `mseccfg.MML` is set to 1, a PMP entry with `L=1, R=0, W=0, X=1` results in a locked execute-only region for M-mode and an access exception for S/U-mode.
RULE 11: If `mseccfg.MML` is set to 1, a PMP entry with `L=1, R=0, W=1, X=0` results in a locked shared code region that is execute-only for both M-mode and S/U-mode.
RULE 12: If `mseccfg.MML` is set to 1, a PMP entry with `L=1, R=0, W=1, X=1` results in a locked shared code region that is read/execute for M-mode and execute-only for S/U-mode.
RULE 13: If `mseccfg.MML` is set to 1, a PMP entry with `L=1, R=1, W=0, X=0` results in a locked read-only region for M-mode and an access exception for S/U-mode.
RULE 14: If `mseccfg.MML` is set to 1, a PMP entry with `L=1, R=1, W=0, X=1` results in a locked read/execute region for M-mode and an access exception for S/U-mode.
RULE 15: If `mseccfg.MML` is set to 1, a PMP entry with `L=1, R=1, W=1, X=0` results in a locked read/write region for M-mode and an access exception for S/U-mode.
RULE 16: If `mseccfg.MML` is set to 1, a PMP entry with `L=1, R=1, W=1, X=1` results in a locked shared data region that is read-only for both M-mode and S/U-mode.
RULE 17: If a field in `mseccfg` is `MMWP` or `MML` and it is set to 1, the field is locked and further writes to it are ignored.
RULE 18: If a field in `mseccfg` is `RLB` and it is set to 0, the field is locked and further writes to it are ignored.
