RULE 1: All S-mode instruction fetches implicitly read the satp CSR.
RULE 2: When mstatus.TVM=1, attempts to read the satp CSR while executing in S-mode shall raise an illegal-instruction exception.
RULE 3: When mstatus.TVM=1, attempts to write the satp CSR while executing in S-mode shall raise an illegal-instruction exception.
RULE 4: When mstatus.TVM=0, reads and writes to the satp CSR are permitted in S-mode.
RULE 5: If S-mode is not supported or if satp.MODE is read-only 0, mstatus.SUM is read-only 0.
