RULE 1: If rs1 = x0 and rs2 = x0, SFENCE.VMA orders all reads and writes made to any level of the page tables for all address spaces and invalidates all address-translation cache entries for all address spaces.
RULE 2: If rs1 = x0 and rs2 ≠ x0, SFENCE.VMA orders all reads and writes made to any level of the page tables for the address space identified by integer register rs2, except for accesses to global mappings, and invalidates all address-translation cache entries matching the address space identified by integer register rs2, except for entries containing global mappings.
RULE 3: If rs1 ≠ x0 and rs2 = x0, SFENCE.VMA orders only reads and writes made to leaf page table entries corresponding to the virtual address in rs1 for all address spaces and invalidates all address-translation cache entries that contain leaf page table entries corresponding to the virtual address in rs1 for all address spaces.
RULE 4: If rs1 ≠ x0 and rs2 ≠ x0, SFENCE.VMA orders only reads and writes made to leaf page table entries corresponding to the virtual address in rs1 for the address space identified by integer register rs2, except for accesses to global mappings, and invalidates all address-translation cache entries that contain leaf page table entries corresponding to the virtual address in rs1 and match the address space identified by integer register rs2, except for entries containing global mappings.
RULE 5: If the value held in rs1 is not a valid virtual address, SFENCE.VMA has no effect and no exception is raised.
RULE 6: If rs2 ≠ x0, the implementation shall ignore bits ASIDMAX-1:ASIDLEN of the value held in rs2.
RULE 7: If the implementation makes satp.MODE read-only zero, attempts to execute an SFENCE.VMA instruction might raise an illegal-instruction exception.
RULE 8: SFENCE.VMA orders previous stores already visible to the current RISC-V hart before subsequent implicit references by that hart to the memory-management data structures.
RULE 9: SFENCE.VMA orders only the local hart's implicit references to the memory-management data structures.
RULE 10: An implicit read of memory-management data structures may return any translation for an address that was valid at any time since the most recent SFENCE.VMA that subsumes that address.
RULE 11: Speculative executions of the address-translation algorithm must not create address-translation cache entries if those entries would have been invalidated by any SFENCE.VMA instruction executed by the hart since the speculative execution began.
