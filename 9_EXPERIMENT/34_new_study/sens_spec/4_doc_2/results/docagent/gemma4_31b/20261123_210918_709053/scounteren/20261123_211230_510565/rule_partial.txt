RULE 1: If the current privilege level is Supervisor-mode or higher, the `scounteren` CSR (address 0x106) is readable and writable.
RULE 2: When a counter i is delegated (mcounteren[i]=1 and menvcfg.CDE=1), the register state associated with counter i can be read or written via sireg* while siselect holds 0x40+i.
RULE 3: While the privilege mode is M or S and siselect holds a value in the range 0x40-0x5F, an attempt to access sireg* when the counter selected by siselect is not delegated to S-mode (the corresponding bit in mcounteren = 0) raises an illegal-instruction exception.
RULE 4: When the CY bit in the scounteren register is clear, attempts to read the cycle register while executing in U-mode will cause an illegal-instruction exception.
RULE 5: When the CY bit in the scounteren register is set, access to the cycle register is permitted while executing in U-mode, provided the corresponding bit in mcounteren is also set.
RULE 6: When the TM bit in the scounteren register is clear, attempts to read the time register while executing in U-mode will cause an illegal-instruction exception.
RULE 7: When the TM bit in the scounteren register is set, access to the time register is permitted while executing in U-mode, provided the corresponding bit in mcounteren is also set.
RULE 8: When the IR bit in the scounteren register is clear, attempts to read the instret register while executing in U-mode will cause an illegal-instruction exception.
RULE 9: When the IR bit in the scounteren register is set, access to the instret register is permitted while executing in U-mode, provided the corresponding bit in mcounteren is also set.
RULE 10: When the HPMn bit in the scounteren register is clear, attempts to read the hpmcountern register while executing in U-mode will cause an illegal-instruction exception.
RULE 11: When the HPMn bit in the scounteren register is set, access to the hpmcountern register is permitted while executing in U-mode, provided the corresponding bit in mcounteren is also set.
RULE 12: If a bit in the scounteren register is read-only zero, reads to the corresponding counter will cause an exception when executing in U-mode.
RULE 13: All bits in the scounteren register are WARL fields.
RULE 14: When V=1, the scounteren CSR continues to have its usual function and accessibility, with VS-mode and VU-mode substituting for HS-mode and U-mode.
RULE 15: In VU-mode, when V=1, an attempt to access a non-high-half counter CSR when the corresponding bit in scounteren is 0 and the same bit in mcounteren is 1 causes a virtual-instruction exception.
RULE 16: In VU-mode, when V=1, if XLEN=32, an attempt to access a high-half counter CSR when the corresponding bit in scounteren is 0 and the same bit in mcounteren is 1 causes a virtual-instruction exception.
