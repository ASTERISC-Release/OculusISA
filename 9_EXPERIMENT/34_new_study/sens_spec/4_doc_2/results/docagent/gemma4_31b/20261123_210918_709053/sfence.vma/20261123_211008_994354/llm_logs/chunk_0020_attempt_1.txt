RULE 1: When the PMP settings are modified and the hart implements virtual memory, M-mode software must execute an SFENCE.VMA instruction with rs1 = x0 and rs2 = x0 to synchronize the PMP settings with the virtual memory system and any PMP or address-translation caches.
RULE 2: If page-based virtual memory is not implemented, no SFENCE.VMA is needed because memory accesses check the PMP settings synchronously.
