RULE 1: If S-mode is not supported, or if satp.MODE is read-only zero, the implementation may make menvcfg.FIOM read-only zero.
RULE 2: When menvcfg.PBMTE is set to 1, the Svpbmt extension is available for page tables pointed to by satp.
RULE 3: When menvcfg.PBMTE is set to 0, the implementation behaves as though Svpbmt were not implemented for page tables pointed to by satp.
