RULE 1: When the FCVT.W.D instruction is executed, it uses the floating-point register rs1 as the source operand.
RULE 2: When the FCVT.W.D instruction is executed, the result is written to the integer destination register rd.
RULE 3: When the FCVT.W.D instruction is executed, the rounding mode is determined by the rm field of the instruction, unless the rm field is 111, in which case the dynamic rounding mode held in the frm field of the fcsr register is used.
RULE 4: When the FCVT.W.D instruction is executed, it may accumulate the NV (Invalid Operation) exception flag in the fcsr register.
RULE 5: When the FCVT.W.D instruction is executed, it may accumulate the NX (Inexact) exception flag in the fcsr register.
RULE 6: FCVT.W.D converts a double-precision floating-point number in floating-point register rs1 to a signed 32-bit integer in integer register rd.
RULE 7: FCVT.W.D rounds the result according to the rm field.
RULE 8: If XLEN > 32, FCVT.W.D sign-extends the 32-bit result to the destination register width.
RULE 9: If the rounded result of FCVT.W.D is not representable in the destination format, the result is clipped to the nearest value and the invalid flag is set.
RULE 10: If the rounded result of FCVT.W.D is an out-of-range negative input, the output is -2^31.
RULE 11: If the rounded result of FCVT.W.D is -∞, the output is -2^31.
RULE 12: If the rounded result of FCVT.W.D is an out-of-range positive input, the output is 2^31 - 1.
RULE 13: If the rounded result of FCVT.W.D is +∞ or NaN, the output is 2^31 - 1.
RULE 14: FCVT.W.D sets the Inexact exception flag if the rounded result differs from the operand value and the Invalid exception flag is not set.
RULE 15: If the input operand for FCVT.W.D is a narrower n-bit value (n < FLEN), FCVT.W.D treats the input as an n-bit canonical NaN if the upper FLEN-n bits are not all 1s.
RULE 16: If the input operand for FCVT.W.D is a narrower n-bit value (n < FLEN) and the upper FLEN-n bits are all 1s, FCVT.W.D uses the n least-significant bits as the input value.
