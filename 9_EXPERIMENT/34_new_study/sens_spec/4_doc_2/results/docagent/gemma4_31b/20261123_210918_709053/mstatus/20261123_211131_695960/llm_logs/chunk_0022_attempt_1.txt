RULE 1: If the SUM bit in the mstatus register is set, supervisor mode software may access pages with U=1 in the page table entry.
RULE 2: If the SUM bit in the mstatus register is clear, supervisor mode software will fault on accesses to pages with U=1 in the page table entry.
RULE 3: The requested memory access is allowed by the pte.u bit based on the current privilege mode and the value of the SUM field of the mstatus register.
RULE 4: The requested memory access is allowed by the pte.u bit based on the current privilege mode and the value of the MXR field of the mstatus register.
