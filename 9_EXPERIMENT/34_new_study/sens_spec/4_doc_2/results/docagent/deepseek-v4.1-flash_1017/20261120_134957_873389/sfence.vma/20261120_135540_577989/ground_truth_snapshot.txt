RULE 1: When TVM=1, attempting to execute an SFENCE.VMA instruction while executing in S-mode raises an illegal-instruction exception.
RULE 2: When TVM=0, attempting to execute an SFENCE.VMA instruction is permitted in S-mode.
RULE 3: If the value held in rs1 of an SFENCE.VMA instruction is not a valid virtual address, no exception is raised by the SFENCE.VMA instruction.
RULE 4: For an SFENCE.VMA instruction where rs2 ≠ x0, bits SXLEN-1:ASIDMAX of the value held in rs2 are reserved for future standard use.
RULE 5: Changing satp.MODE from Bare to other modes and vice versa takes effect immediately, without the need to execute an SFENCE.VMA instruction.
RULE 6: An attempt to execute the SFENCE.VMA instruction in U-mode always raises an illegal-instruction exception.
RULE 7: An attempt to execute the SFENCE.VMA instruction in S-mode or HS-mode when mstatus.TVM is 1 raises an illegal-instruction exception.
RULE 8: An attempt to execute the SFENCE.VMA instruction in VU-mode raises a virtual-instruction exception.
RULE 9: When hstatus.VTVM is 1, an attempt to execute the SFENCE.VMA instruction in VS-mode raises a virtual-instruction exception.
RULE 10: When VTVM is set to 1, an attempt in VS-mode to execute SFENCE.VMA raises a virtual-instruction exception.
RULE 11: An attempt to execute an SFENCE.VMA instruction in VU-mode raises a virtual-instruction exception.
RULE 12: When V=1, an attempt to execute an SFENCE.VMA instruction raises a virtual-instruction exception with code 22 instead of an illegal-instruction exception if the instruction is HS-qualified but is prevented from executing due to insufficient privilege or because it is expressly disabled by a supervisor or hypervisor CSR.
RULE 13: On a virtual-instruction trap caused by an SFENCE.VMA instruction, mtval or stval is written the same as for an illegal-instruction trap.
RULE 14: If an SFENCE.VMA instruction raises multiple synchronous exceptions, a virtual-instruction exception has a lower priority than an illegal instruction exception but a higher priority than an instruction address misaligned exception for determining which exception is taken and reported in mcause or scause.
