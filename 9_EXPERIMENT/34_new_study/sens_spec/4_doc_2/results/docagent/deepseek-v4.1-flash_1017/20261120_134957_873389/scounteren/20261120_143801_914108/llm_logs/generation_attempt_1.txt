RULE 1: The scounteren CSR is implemented as a supervisor CSR accessible in S-mode or a higher privilege mode.
RULE 2: If scounteren.CY is clear, an attempt to read cycle while executing in U-mode raises an illegal-instruction exception.
RULE 3: If scounteren.TM is clear, an attempt to read time while executing in U-mode raises an illegal-instruction exception.
RULE 4: If scounteren.IR is clear, an attempt to read instret while executing in U-mode raises an illegal-instruction exception.
RULE 5: For any hpmcountern with n in 3 through 31, if scounteren.HPMn is clear, an attempt to read hpmcountern while executing in U-mode raises an illegal-instruction exception.
RULE 6: If scounteren.CY and mcounteren.CY are both set, a read of cycle in U-mode is permitted.
RULE 7: If scounteren.TM and mcounteren.TM are both set, a read of time in U-mode is permitted.
RULE 8: If scounteren.IR and mcounteren.IR are both set, a read of instret in U-mode is permitted.
RULE 9: For any hpmcountern with n in 3 through 31, if scounteren.HPMn and mcounteren.HPMn are both set, a read of hpmcountern in U-mode is permitted.
RULE 10: In U-mode, if the corresponding scounteren bit is set but the corresponding mcounteren bit is clear, a read of that counter raises an illegal-instruction exception.
RULE 11: The value of a bit in mcounteren does not affect whether the corresponding bit in scounteren is writable.
RULE 12: For each writable counter-enable bit in scounteren, a write of an unsupported value does not itself raise an illegal-instruction exception and a subsequent read returns a legal value.
RULE 13: If a scounteren counter-enable bit is implemented as read-only zero, writes to that bit are ignored and the bit reads as zero.
RULE 14: While V=1, scounteren continues its counter-enable function with VU-mode substituting for U-mode.
RULE 15: While V=1, an access to scounteren from VS-mode accesses scounteren and is not redirected to a separate VS CSR.
RULE 16: In VU-mode, if the corresponding scounteren bit is clear and the corresponding mcounteren bit is set, an attempt to access a non-high-half counter CSR raises a virtual-instruction exception.
RULE 17: In VU-mode with XLEN=32, if the corresponding scounteren bit is clear and the corresponding mcounteren bit is set, an attempt to access a high-half counter CSR raises a virtual-instruction exception.
RULE 18: In VU-mode, a read of a counter is permitted only when the corresponding bits in both hcounteren and scounteren are set.
