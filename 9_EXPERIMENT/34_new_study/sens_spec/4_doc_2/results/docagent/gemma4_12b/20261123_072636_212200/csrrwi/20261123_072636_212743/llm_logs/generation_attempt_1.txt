### 1. What happens when the `mstatus.MPV` bit is set?
The `mstatus.MPV` bit (Machine Previous Virtualization mode) is written by the implementation whenever a trap is taken into M-mode. It is set to the value of the virtualization mode `V` at the time of the trap. This bit helps the system keep track of the previous virtualization state before a trap occurred.

### 2. When is the `hstatus.VGEIN` field used?
The `hstatus.VGEIN` field selects a guest external interrupt source for VS-level external interrupts. It is used to determine which specific guest external interrupt signal is routed to the virtual supervisor mode.

### 3. What is the purpose of the `mcounteren` register?
The `mcounteren` register is used to control the availability of the hardware performance-monitoring counters to the next-lower privileged mode. For example, if a bit in this register is clear, attempts to read the corresponding counter (like `mcycle` or `minstret`) from a lower privilege level (S-mode or U-mode) will cause an illegal-instruction exception.

### 4. What is the difference between `SRET` and `MRET`?
*   **`MRET`**: Used to return from a trap taken into M-mode. It updates the privilege mode, sets `mstatus` fields (like `MIE` and `MPIE`), and sets the PC to the value in `mepc`.
*   **`SRET`**: Used to return from a trap taken into HS-mode or VS-mode. Its behavior depends on the current virtualization mode (V). It sets the privilege mode based on `hstatus.SPV` and `sstatus.SPP`, clears certain status bits, and sets the PC to the value in `sepc`.

### 5. What are the two requirements for a `mtime` interrupt to be taken?
An interrupt will trap to M-mode if:
1.  Either the current privilege mode is M and the `MIE` bit in the `mstatus` register is set, **OR** the current privilege mode is less than M-mode.
2.  The corresponding bit is set in **both** the `mip` (interrupt-pending) and `mie` (interrupt-enable) registers.
3.  (If `mideleg` exists) The corresponding bit is **not** set in the `mideleg` register.

### 6. What does the `mepc` register hold?
The `mepc` register holds the virtual address of the instruction that was interrupted or that encountered the exception when a trap is taken into M-mode. It is an MXLEN-bit read/write register where the low bit (`mepc[0]`) is always zero.

### 7. What happens to the `mstatus.MPV` bit during an `MRET` instruction?
During an `MRET` instruction, the `mstatus.MPV` bit is set to 0 (provided `MPP` is not 3). This occurs as part of the process where the privilege mode is restored and the `MIE` and `MPIE` bits are updated.

### 8. What are the two types of "page-fault" exceptions?
The text distinguishes between:
*   **Page-fault exceptions**: These occur during address translation (typically when a page table entry is invalid or lacks proper permissions).
*   **Guest-page-fault exceptions**: These are specific to the hypervisor extension (V=1). They occur during the second stage of address translation (G-stage) when the guest-physical address translation fails.

### 9. How does `mideleg` affect the `mip` and `mie` registers?
The `mideleg` register is used to delegate traps from M-mode to a lower privilege level. If a bit in `mideleg` is set, the corresponding interrupt will not trap to M-mode; instead, it will be handled by the lower privilege level (provided it is enabled in that level's `sie` or `sie` equivalent).

### 10. What is the purpose of the `mtval` register?
The `mtval` register is used to provide exception-specific information to assist software in handling a trap. For example, it may contain the faulting virtual address for access faults, page faults, or hardware errors. It can also be used to return the faulting instruction bits for illegal-instruction exceptions.

### 11. What is the `mscratch` register?
The `mscratch` register is an MXLEN-bit read/write register dedicated for use by machine mode. It is typically used to hold a pointer to a machine-mode hart-local context space and is swapped with a user register upon entry to an M-mode trap handler.

### 12. What is the `mcause` register?

### 13. What is the `mconfigptr` register?
