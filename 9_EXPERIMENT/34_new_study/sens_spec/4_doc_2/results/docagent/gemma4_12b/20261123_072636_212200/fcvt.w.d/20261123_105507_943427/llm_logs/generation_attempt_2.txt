### **Definition and Purpose**
The **$mepc$** (Machine Exception Program Counter) is an **MXLEN-bit read/write register** used to hold the virtual address of the instruction that was interrupted or encountered an exception when a trap is taken into machine mode.

### **Key Characteristics**
*   **Alignment:** The low bit (**$mepc[0]$**) is always zero. If the implementation only supports IALIGN=32, the two low bits (**$mepc[1:0]$**) are always zero.
*   **Masking:** If an implementation allows IALIGN to be either 16 or 32, bit **$mepc[1]$** is masked on reads to appear as 0 whenever IALIGN=32. However, bit **$mepc[1]$** remains writable in that mode.
*   **Address Range:** It is a **WARL** (Write Anything, Read Like) register that must be capable of holding all valid virtual addresses.
*   **Write Behavior:** When a trap is taken into M-mode, the hardware writes the virtual address of the instruction that was interrupted or encountered the exception into this register. Otherwise, it is never written by the hardware (though it may be explicitly written by software).
