RULE 1: SFENCE.VMA with rs1 = x0 and rs2 = x0 orders all previous stores visible to the current hart before all implicit references to the memory-management data structures for any level of the page tables for all address spaces on the local hart.
RULE 2: SFENCE.VMA with rs1 = x0 and rs2 = x0 invalidates all address-translation cache entries for all address spaces on the local hart.
RULE 3: SFENCE.VMA with rs1 = x0 and rs2 ≠ x0 orders all previous stores visible to the current hart before all implicit references to the memory-management data structures for any level of the page tables for the address space identified by integer register rs2 on the local hart.
RULE 4: SFENCE.VMA with rs1 = x0 and rs2 ≠ x0 does not order accesses to global mappings for the address space identified by integer register rs2 on the local hart.
RULE 5: SFENCE.VMA with rs1 = x0 and rs2 ≠ x0 invalidates all address-translation cache entries matching the address space identified by integer register rs2, excluding entries containing global mappings, on the local hart.
RULE 6: SFENCE.VMA with rs1 ≠ x0 and rs2 = x0 orders all previous stores visible to the current hart before all implicit references to the memory-management data structures for leaf page table entries corresponding to the virtual address in rs1 for all address spaces on the local hart.
