RULE 1: When V=0, the virtual-address argument of SFENCE.VMA is an HS-level virtual address.
RULE 2: When V=0, the ASID argument of SFENCE.VMA is an HS-level ASID.
RULE 3: When V=0, the SFENCE.VMA instruction orders stores only to HS-level address-translation structures with subsequent HS-level address translations.
RULE 4: When V=1, the virtual-address argument of SFENCE.VMA is a guest virtual address within the current virtual machine.
RULE 5: When V=1, the ASID argument of SFENCE.VMA is a VS-level ASID within the current virtual machine.
RULE 6: When V=1, the SFENCE.VMA instruction orders stores only to the VS-level address-translation structures with subsequent VS-stage address translations for instructions that execute when hgatp.VMID is the same as it was when the SFENCE.VMA instruction was executed.
RULE 7: When V=1 and hstatus.VTVM=1, an attempt to execute SFENCE.VMA in VS-mode causes a virtual-instruction exception.
