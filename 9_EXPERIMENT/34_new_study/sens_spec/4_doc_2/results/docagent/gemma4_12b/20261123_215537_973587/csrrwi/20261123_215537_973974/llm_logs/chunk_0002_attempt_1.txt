RULE 1: If rd is x0, the CSRRWI instruction does not read the CSR.
RULE 2: If rd is x0, the CSRRWI instruction does not cause any side effects from a CSR read.
RULE 3: If rd is not x0, the CSRRWI instruction reads the CSR.
RULE 4: If the 5-bit unsigned immediate uimm is 0, the CSRRWI instruction does not write to the CSR.
RULE 5: If the 5-bit unsigned immediate uimm is 0, the CSRRWI instruction does not cause any side effects from a CSR write.
RULE 6: If the 5-bit unsigned immediate uimm is 0, the CSRRWI instruction does not raise an illegal-instruction exception on access to a read-only CSR.
RULE 7: If the 5-bit unsigned immediate uimm is not 0, the CSRRWI instruction writes the zero-extended 5-bit unsigned immediate to the CSR.
RULE 8: If rd is not x0, the CSRRWI instruction writes the old CSR value (zero-extended to XLEN bits) to register rd.
