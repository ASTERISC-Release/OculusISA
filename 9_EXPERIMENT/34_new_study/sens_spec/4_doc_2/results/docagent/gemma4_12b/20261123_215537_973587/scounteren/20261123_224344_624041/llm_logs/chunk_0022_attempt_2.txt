RULE 1: If the CY bit in the scounteren register is clear, a read of the cycle register in U-mode causes an illegal-instruction exception.
RULE 2: If the TM bit in the scounteren register is clear, a read of the time register in U-mode causes an illegal-instruction exception.
RULE 3: If the IR bit in the scounteren register is clear, a read of the instret register in U-mode causes an illegal-instruction exception.
RULE 4: If the HPMn bit in the scounteren register is clear, a read of the hpmcounter(n) register in U-mode causes an illegal-instruction exception.
RULE 5: If the corresponding bit in the mcounteren register is clear, an access to the corresponding counter in U-mode causes an illegal-instruction exception.
RULE 6: If the corresponding bit in the scounteren register is set and the corresponding bit in the mcounteren register is set, access to the corresponding counter in U-mode is permitted.
RULE 7: Setting a bit in the mcounteren register does not affect the writability of the corresponding bit in the scounteren register.
