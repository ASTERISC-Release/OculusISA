RULE 1: If Pointer Masking is enabled and an explicit memory access to a physical address (including guest-physical addresses) is performed, the ignore transformation replaces the upper PMLEN bits of the address with 0 if the satp register's MODE field is Bare.
RULE 2: If Pointer Masking is enabled and an explicit memory access to a virtual address is performed, the ignore transformation replaces the upper PMLEN bits of the address with the sign extension of the PMLEN+1st bit if the satp register's MODE field is not equal to Bare.
