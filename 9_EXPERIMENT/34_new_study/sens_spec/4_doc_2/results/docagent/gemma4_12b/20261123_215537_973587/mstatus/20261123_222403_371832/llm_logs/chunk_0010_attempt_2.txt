RULE 1: If mstatus.FS is Off, executing a vector floating-point instruction raises an illegal-instruction exception.
RULE 2: If a vector floating-point instruction modifies any floating-point extension state (floating-point CSRs or f registers), mstatus.FS is set to Dirty.
RULE 3: If the hypervisor extension is implemented, V is 1, and vsstatus.FS is Off, executing a vector floating-point instruction raises an illegal-instruction exception.
RULE 4: If the hypervisor extension is implemented, V is 1, and a vector floating-point instruction modifies any floating-point extension state (floating-point CSRs or f registers), vsstatus.FS is set to Dirty.
