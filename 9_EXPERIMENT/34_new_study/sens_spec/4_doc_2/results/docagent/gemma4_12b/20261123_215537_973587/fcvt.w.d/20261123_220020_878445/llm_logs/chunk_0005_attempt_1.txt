RULE 1: FCVT.W.D converts a double-precision floating-point number from floating-point register rs1 to a signed 32-bit integer in integer register rd.
RULE 2: FCVT.W.D rounds the conversion result according to the value in the rm field.
RULE 3: If the rounded result of FCVT.W.D is less than -2^31, the value in integer register rd is -2^31.
RULE 4: If the input to FCVT.W.D is -∞, the value in integer register rd is -2^31.
RULE 5: If the rounded result of FCVT.W.D is greater than 2^31 - 1, the value in integer register rd is 2^31 - 1.
RULE 6: If the input to FCVT.W.D is +∞, the value in integer register rd is 2^31 - 1.
RULE 7: If the input to FCVT.W.D is NaN, the value in integer register rd is 2^31 - 1.
RULE 8: If the rounded result of FCVT.W.D is not representable in the 32-bit signed integer format, the value in integer register rd is clipped to the nearest representable value.
RULE 9: If the rounded result of FCVT.W.D is not representable in the 32-bit signed integer format, the invalid exception flag is set.
RULE 10: If the rounded result of FCVT.W.D differs from the operand value and the invalid exception flag is not set, the inexact exception flag is set.
RULE 11: If XLEN is 64, the 32-bit result of FCVT.W.D is sign-extended to the 64-bit width of integer register rd.
