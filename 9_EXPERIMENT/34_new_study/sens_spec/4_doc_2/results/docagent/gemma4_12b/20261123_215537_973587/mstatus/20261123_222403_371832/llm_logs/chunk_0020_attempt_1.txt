RULE 1: If an RNMI interrupt signal is received, the interrupt is not disabled by the state of the mstatus.MIE bit.
RULE 2: If the hart is in M-mode, the mstatus.MPRV bit is set, and the mstatus.MPP field contains S or U, then PMP checks are applied to data accesses.
RULE 3: If the mnstatus.NMIE bit is 0, the hart behaves as though the mstatus.MPRV bit were clear.
RULE 4: If the MNRET instruction changes the privilege mode to a mode less privileged than M, the mstatus.MPRV bit is set to 0.
