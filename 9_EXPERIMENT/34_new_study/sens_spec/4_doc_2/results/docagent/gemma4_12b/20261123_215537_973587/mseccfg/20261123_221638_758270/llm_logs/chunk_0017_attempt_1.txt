RULE 1: The CSR `mseccfg` is located at address `0x747`.
RULE 2: The CSR `mseccfg` is accessible for read operations in machine mode.
RULE 3: The CSR `mseccfg` is accessible for write operations in machine mode.
RULE 4: An access to the CSR `mseccfg` from a privilege level lower than machine mode results in an illegal-instruction exception.
RULE 5: The CSR `mseccfgh` is located at address `0x757`.
RULE 6: The CSR `mseccfgh` is accessible for read operations in machine mode.
RULE 7: The CSR `mseccfgh` is accessible for write operations in machine mode.
RULE 8: In the RV32 architecture, the CSR `mseccfgh` represents the upper 32 bits of the `mseccfg` register.
