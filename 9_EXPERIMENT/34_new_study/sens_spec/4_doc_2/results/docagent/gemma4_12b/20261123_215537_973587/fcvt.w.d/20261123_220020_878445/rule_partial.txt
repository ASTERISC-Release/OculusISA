RULE 1: The FCVT.W.D instruction uses the floating-point register rs1 as a source operand.
RULE 2: The FCVT.W.D instruction uses the rounding mode frm as a source operand.
RULE 3: The FCVT.W.D instruction writes the converted result to the floating-point register rd.
RULE 4: If the rm field of the FCVT.W.D instruction is 111, the instruction uses the dynamic rounding mode held in frm.
RULE 5: If the rm field of the FCVT.W.D instruction is not 111, the instruction uses the static rounding mode encoded in the rm field.
RULE 6: If the rm field of the FCVT.W.D instruction is 111, the instruction can set the NV flag in the fcsr register.
RULE 7: If the rm field of the FCVT.W.D instruction is 111, the instruction can set the NX flag in the fcsr register.
RULE 8: FCVT.W.D converts a double-precision floating-point number from floating-point register rs1 to a signed 32-bit integer in integer register rd.
RULE 9: FCVT.W.D rounds the conversion result according to the value in the rm field.
RULE 10: If the rounded result of FCVT.W.D is less than -2^31, the value in integer register rd is -2^31.
RULE 11: If the input to FCVT.W.D is -∞, the value in integer register rd is -2^31.
RULE 12: If the rounded result of FCVT.W.D is greater than 2^31 - 1, the value in integer register rd is 2^31 - 1.
RULE 13: If the input to FCVT.W.D is +∞, the value in integer register rd is 2^31 - 1.
RULE 14: If the input to FCVT.W.D is NaN, the value in integer register rd is 2^31 - 1.
RULE 15: If the rounded result of FCVT.W.D is not representable in the 32-bit signed integer format, the value in integer register rd is clipped to the nearest representable value.
RULE 16: If the rounded result of FCVT.W.D is not representable in the 32-bit signed integer format, the invalid exception flag is set.
RULE 17: If the rounded result of FCVT.W.D differs from the operand value and the invalid exception flag is not set, the inexact exception flag is set.
RULE 18: If XLEN is 64, the 32-bit result of FCVT.W.D is sign-extended to the 64-bit width of integer register rd.
RULE 19: The FCVT.W.D instruction converts a double-precision floating-point value from register rs1 into a 32-bit word.
RULE 20: The result of the conversion performed by the FCVT.W.D instruction is stored in register rd.
RULE 21: The FCVT.W.D instruction uses the rounding mode specified in the rm field to perform the conversion.
