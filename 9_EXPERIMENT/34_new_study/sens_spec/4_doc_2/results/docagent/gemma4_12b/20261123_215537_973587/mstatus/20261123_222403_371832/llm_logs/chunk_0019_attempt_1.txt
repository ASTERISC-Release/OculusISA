RULE 1: Upon reset, the mstatus.MIE field is set to 0.
RULE 2: Upon reset, the mstatus.MPRV field is set to 0.
RULE 3: If littleendian memory accesses are supported, the mstatus.MBE field is set to 0 upon reset.
RULE 4: If the mstatus.TSR field is 1, the SRET instruction raises an illegal-instruction exception.
RULE 5: If the mstatus.TW field is 1, the WFI instruction raises an illegal-instruction exception.
