RULE 1: A hart in Machine mode may read the scounteren CSR at address 0x106.
RULE 2: A hart in Supervisor mode may read the scounteren CSR at address 0x106.
RULE 3: A hart in Machine mode may write to the scounteren CSR at address 0x106.
RULE 4: A hart in Supervisor mode may write to the scounteren CSR at address 0x106.
RULE 5: An attempt to read the scounteren CSR at address 0x106 by a hart in User mode shall raise an illegal-instruction exception.
RULE 6: An attempt to write to the scounteren CSR at address 0x106 by a hart in User mode shall raise an illegal-instruction exception.
RULE 7: A read from the scounteren CSR at address 0x106 shall have no side effects.
RULE 8: If the CY bit in the scounteren register is clear, a read of the cycle register in U-mode causes an illegal-instruction exception.
RULE 9: If the TM bit in the scounteren register is clear, a read of the time register in U-mode causes an illegal-instruction exception.
RULE 10: If the IR bit in the scounteren register is clear, a read of the instret register in U-mode causes an illegal-instruction exception.
RULE 11: If the HPMn bit in the scounteren register is clear, a read of the hpmcounter(n) register in U-mode causes an illegal-instruction exception.
RULE 12: If the corresponding bit in the mcounteren register is clear, an access to the corresponding counter in U-mode causes an illegal-instruction exception.
RULE 13: If the corresponding bit in the scounteren register is set and the corresponding bit in the mcounteren register is set, access to the corresponding counter in U-mode is permitted.
RULE 14: Setting a bit in the mcounteren register does not affect the writability of the corresponding bit in the scounteren register.
RULE 15: When the virtualization mode V is 1, the scounteren CSR has no matching VS CSR.
RULE 16: When the virtualization mode V is 1, the scounteren CSR is accessible in VS-mode.
RULE 17: When the virtualization mode V is 1, the scounteren CSR is accessible in VU-mode.
RULE 18: When virtualization mode V=1 and an HS-qualified instruction is prevented from executing because it is expressly disabled by the scounteren CSR, a virtual-instruction exception (code 22) is raised.
