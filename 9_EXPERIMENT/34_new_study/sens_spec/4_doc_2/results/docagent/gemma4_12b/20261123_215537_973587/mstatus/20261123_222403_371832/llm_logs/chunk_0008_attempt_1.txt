RULE 1: If mstatus.VS is Off, attempting to execute any vector instruction or access any vector CSR raises an illegal-instruction exception.
RULE 2: If mstatus.VS is Initial or Clean, executing any instruction that changes vector state, including the vector CSRs, results in mstatus.VS being set to Dirty.
RULE 3: If mstatus.VS is Dirty, mstatus.SD is set to 1.
