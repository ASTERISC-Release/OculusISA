RULE 1: If mstatus.TVM=1, an attempt to execute the SINVAL.VMA instruction in S-mode or HS-mode raises an illegal-instruction exception.
RULE 2: If mstatus.TVM=1, an attempt to execute the HINVAL.GVMA instruction in S-mode or HS-mode raises an illegal-instruction exception.
RULE 3: If mstatus.TVM=1, the SFENCE.W.INVAL instruction does not need to be trapped.
RULE 4: If mstatus.TVM=1, the SFENCE.INVAL.IR instruction does not need to be trapped.
RULE 5: If mstatus.TVM=1, an attempt to read or write the hgatp CSR while executing in HS-mode raises an illegal-instruction exception.
