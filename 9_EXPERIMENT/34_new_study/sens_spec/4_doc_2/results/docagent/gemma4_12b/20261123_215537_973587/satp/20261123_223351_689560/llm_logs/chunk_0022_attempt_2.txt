RULE 1: The satp CSR is an SXLEN-bit read/write register.
RULE 2: The satp register contains PPN, ASID, and MODE fields.
RULE 3: The satp.PPN field holds the physical page number of the root page table, which is the supervisor physical address divided by 4 KiB.
RULE 4: The satp.ASID field holds an address space identifier to facilitate address-translation fences on a per-addressspace basis.
RULE 5: The satp.MODE field selects the current address-translation scheme.
RULE 6: When SXLEN=32, the satp encodings corresponding to MODE=Bare and ASID[8:7]=3 are designated for custom use.
RULE 7: When SXLEN=32, the satp encodings corresponding to MODE=Bare and ASID[8:7]≠3 are reserved for future standard use.
RULE 8: When SXLEN=64, all satp encodings corresponding to MODE=Bare are reserved for future standard use.
RULE 9: When the satp.MODE field is set to Bare, supervisor virtual addresses are equal to supervisor physical addresses.
RULE 10: When the satp.MODE field is set to Bare, there is no additional memory protection beyond the physical memory protection scheme.
RULE 11: To select MODE=Bare when SXLEN=32, software must write zero to the remaining fields of satp (bits 30-0).
RULE 12: To select MODE=Bare when SXLEN=64, software must write zero to the remaining fields of satp (bits 59-0).
RULE 13: When SXLEN=32, the only valid setting for the satp.MODE field other than Bare is Sv32.
RULE 14: When SXLEN=64, the valid settings for the satp.MODE field are Sv39, Sv48, and Sv57.
RULE 15: If satp is written with an unsupported MODE, the entire write has no effect and no fields in satp are modified.
RULE 16: The number of ASID bits in the satp.ASID field is UNSPECIFIED.
RULE 17: The number of implemented ASID bits (ASIDLEN) is determined by writing a one to every bit position in the ASID field and reading back the value in satp.
RULE 18: If ASIDLEN is greater than 0, the bits ASID[ASIDLEN-1:0] in the satp register are writable.
RULE 19: The maximal value of ASIDLEN is 9 for Sv32 and 16 for Sv39, Sv48, and Sv57.
RULE 20: The satp CSR is considered active when the effective privilege mode is S-mode or U-mode.
RULE 21: The address-translation algorithm may only begin using a given value of satp when satp is active.
RULE 22: Writing satp does not imply any ordering constraints between page-table updates and subsequent address translations.
RULE 23: Writing satp does not imply any invalidation of address-translation caches.
