RULE 1: FCVT.W.D converts the double-precision floating-point value in floating-point register rs1 to a signed 32-bit integer and writes the result to integer register rd.
RULE 2: FCVT.W.D rounds the conversion result according to the rounding mode specified in the rm field of the instruction.
RULE 3: When executed on an RV64 implementation, FCVT.W.D sign-extends the 32-bit integer result to produce a 64-bit value written to integer register rd.
RULE 4: FCVT.W.D must raise the floating-point exception flags that correspond to converting its double-precision source operand to a signed 32-bit integer, and the set of flags raised is identical to those that would be raised for FCVTMOD.W.D with the same operand.
