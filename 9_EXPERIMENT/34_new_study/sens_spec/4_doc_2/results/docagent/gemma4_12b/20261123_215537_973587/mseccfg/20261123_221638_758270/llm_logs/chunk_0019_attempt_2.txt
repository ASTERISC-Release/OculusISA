RULE 1: If mseccfg.USEED is 0, any access to the seed CSR in U-mode raises an illegal-instruction exception.
RULE 2: If mseccfg.USEED is 1, read-write access to the seed CSR in U-mode is permitted.
RULE 3: If mseccfg.USEED is 1, any access to the seed CSR in U-mode other than read-write raises an illegal-instruction exception.
RULE 4: If mseccfg.SEED is 0, any access to the seed CSR from S-mode or HS-mode raises an illegal-instruction exception.
RULE 5: If mseccfg.SEED is 1, read-write access to the seed CSR from S-mode or HS-mode is permitted.
RULE 6: If mseccfg.SEED is 1, any access to the seed CSR from S-mode or HS-mode other than read-write raises an illegal-instruction exception.
RULE 7: If the H extension is implemented and mseccfg.SEED is 1, read-write access to the seed CSR from an HS-qualified instruction in VS-mode or VU-mode raises a virtual-instruction exception.
RULE 8: If the H extension is implemented and mseccfg.SEED is 1, any access to the seed CSR from an HS-qualified instruction in VS-mode or VU-mode other than read-write raises an illegal-instruction exception.
RULE 9: If mseccfg.RLB is 0 and any pmpcfg.L field is 1, any modification to mseccfg.RLB is ignored until a PMP reset.
RULE 10: If mseccfg.MMWP is set, M-mode access to a memory region without a matching PMP rule is denied.
RULE 11: If mseccfg.MML is set and pmpcfg.L is 1, the rule is M-mode-only (enforced on M-mode, denied on S-mode or U-mode).
RULE 12: If mseccfg.MML is set and pmpcfg.L is 0, the rule is S/U-mode-only (enforced on S-mode or U-mode, denied on M-mode).
RULE 13: If mseccfg.MML is set, pmpcfg.L is 0, and pmpcfg.LRWX is 1111, the rule is a Shared-Region where M-mode has read/write access if pmpcfg.X is set and S/U-mode has read access if pmpcfg.X is clear, or read/write access if pmpcfg.X is set.
RULE 14: If mseccfg.MML is set, pmpcfg.L is 1, and pmpcfg.LRWX is 1111, the rule is a Shared-Region where M-mode and S/U-mode have execute access and M-mode has read access if pmpcfg.X is set.
RULE 15: If mseccfg.MML is set and pmpcfg.RW is 01, the rule is a Shared-Region where M-mode and S/U-mode have read-only access.
RULE 16: If mseccfg.MML is set, any write to pmpcfg that attempts to add a rule with executable privileges that is M-mode-only or a locked Shared-Region is ignored.
RULE 17: If mseccfg.MML is set, execution of code in M-mode from a memory region without a matching M-mode-only rule or a locked Shared-Region rule with executable privileges is denied.
RULE 18: If mseccfg.MML is set, execution of code in M-mode from a memory region with a matching S/U-mode-only rule is denied.
RULE 19: If mseccfg.PMM is 00, the PMLEN is 0.
RULE 20: If mseccfg.PMM is 10, the PMLEN is XLEN - 57.
RULE 21: If mseccfg.PMM is 11, the PMLEN is XLEN - 48.
RULE 22: If mseccfg.MLPE is 1, the Zicfilp extension is enabled in M-mode.
RULE 23: If mseccfg.MLPE is 0, the hart does not update the ELP state and the LPAD instruction operates as a no-op.
