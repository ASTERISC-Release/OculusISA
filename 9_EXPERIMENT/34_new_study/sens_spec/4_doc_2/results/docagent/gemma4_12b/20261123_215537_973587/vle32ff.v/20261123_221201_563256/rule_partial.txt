RULE 1: VLE32FF.V is a unit-stride load instruction that transfers 32-bit elements from memory into a destination vector register group.
RULE 2: If a synchronous exception occurs on element 0, VLE32FF.V takes a trap.
RULE 3: If a synchronous exception occurs on element 0, the vl register is not modified.
RULE 4: If a synchronous exception occurs on an element with an index greater than 0, VLE32FF.V does not take a trap.
RULE 5: If a synchronous exception occurs on an element with an index greater than 0, the vl register is reduced to the index of the element that would have raised the exception.
RULE 6: If the vtype.vma bit is 1, inactive elements in the destination vector register group may be overwritten with 1s.
RULE 7: If the vtype.vta bit is 1, tail elements in the destination vector register group may be overwritten with 1s.
RULE 8: If vstart is greater than or equal to vl, no elements in the destination vector register group are updated.
RULE 9: If vl is 0, no elements in the destination vector register group are updated.
RULE 10: If VLE32FF.V takes a trap due to an interrupt, the vl register is not modified.
RULE 11: If VLE32FF.V takes a trap due to an interrupt, the vstart register is set to a value.
RULE 12: If VLE32FF.V would trigger a debug data-watchpoint trap on an element with an index greater than 0, the vl register is not modified and the debug trap is taken.
RULE 13: If the vm bit is 0, only elements where v0.mask[i] is 1 are active.
RULE 14: VLE32FF.V follows RVWMO at the instruction level.
RULE 15: VLE32FF.V follows RVTSO at the instruction level if the Ztso extension is implemented.
RULE 16: Element operations within VLE32FF.V are unordered.
RULE 17: If the destination vector register group overlaps with the source mask register v0, the encoding of VLE32FF.V is reserved.
RULE 18: Only active elements of VLE32FF.V access memory or raise exceptions.
RULE 19: VLE32FF.V may update active destination elements past the point at which vector length is trimmed.
RULE 20: If an element is not naturally aligned to the size of the element, VLE32FF.V may perform a successful transfer or raise an address-misaligned exception.
