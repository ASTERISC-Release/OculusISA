RULE 1: When a hart is executing in S-mode, instruction fetches implicitly read the satp CSR.
RULE 2: When the mstatus.TVM bit is 1 and the hart is executing in S-mode, an attempt to read the satp CSR results in an illegal-instruction exception.
RULE 3: When the mstatus.TVM bit is 1 and the hart is executing in S-mode, an attempt to write the satp CSR results in an illegal-instruction exception.
RULE 4: When the mstatus.TVM bit is 0 and the hart is executing in S-mode, an attempt to read the satp CSR is permitted.
RULE 5: When the mstatus.TVM bit is 0 and the hart is executing in S-mode, an attempt to write the satp CSR is permitted.
RULE 6: If satp.MODE is read-only 0, the SUM bit in the mstatus register is read-only 0.
