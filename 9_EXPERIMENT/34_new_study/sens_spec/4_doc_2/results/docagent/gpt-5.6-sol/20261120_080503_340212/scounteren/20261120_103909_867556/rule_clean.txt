RULE 1: If S-mode is implemented, a properly privileged CSR access to scounteren shall not trap because scounteren is unimplemented.
RULE 2: A CSR instruction executed in M-mode, S-mode, HS-mode, or VS-mode may access scounteren subject to the normal CSR read/write rules.
RULE 3: An attempt to access scounteren from U-mode raises an illegal-instruction exception.
RULE 4: An attempt to access scounteren from VU-mode raises a virtual-instruction exception.
RULE 5: When XLEN is greater than 32, an explicit read of scounteren returns zero in register bits XLEN-1:32.
RULE 6: When XLEN is greater than 32, an explicit write to scounteren ignores source-value bits XLEN-1:32.
RULE 7: If a scounteren bit is implemented as read-only zero, writing that bit leaves it zero without raising an exception merely because the written value is one.
RULE 8: Whether a scounteren bit is writable is independent of the value and writability of the corresponding mcounteren bit.
RULE 9: The scounteren.CY bit is the scounteren control for reads of cycle and, when XLEN=32, cycleh.
RULE 10: The scounteren.TM bit is the scounteren control for reads of time and, when XLEN=32, timeh.
RULE 11: The scounteren.IR bit is the scounteren control for reads of instret and, when XLEN=32, instreth.
RULE 12: For each n from 3 through 31, scounteren.HPMn is the scounteren control for reads of hpmcountern and, when XLEN=32, hpmcounternh.
RULE 13: If U-mode attempts to read a counter CSR whose corresponding scounteren bit is zero, the read raises an illegal-instruction exception.
RULE 14: If U-mode attempts to read a counter CSR whose corresponding scounteren bit is one but whose corresponding mcounteren bit is zero, the read raises an illegal-instruction exception.
RULE 15: If an implemented counter CSR is read in U-mode while its corresponding scounteren and mcounteren bits are both one, the counter-enable controls do not prevent the read from executing.
RULE 16: If VU-mode attempts to read a counter CSR whose corresponding mcounteren bit is zero, the read raises an illegal-instruction exception regardless of the corresponding scounteren and hcounteren bits.
RULE 17: If VU-mode attempts to read a counter CSR whose corresponding mcounteren bit is one and whose corresponding scounteren bit is zero, the read raises a virtual-instruction exception.
RULE 18: If VU-mode attempts to read a counter CSR whose corresponding mcounteren bit is one and whose corresponding hcounteren bit is zero, the read raises a virtual-instruction exception.
RULE 19: If an implemented counter CSR is read in VU-mode while its corresponding mcounteren, hcounteren, and scounteren bits are all one, the counter-enable controls do not prevent the read from executing.
RULE 20: The value of scounteren does not restrict counter reads performed in M-mode, S-mode, HS-mode, or VS-mode.
RULE 21: A VS-mode write to scounteren changes the scounteren state used to control subsequent VU-mode counter reads.
RULE 22: Reading or writing scounteren does not modify the values of the underlying counters.
RULE 23: Clearing a scounteren bit does not inhibit incrementing of the corresponding underlying counter.
RULE 24: A completed write to scounteren is observed by subsequent instructions on the same hart in program order when their counter-access behavior depends on scounteren.
