RULE 1: If S-mode is implemented, the scounteren CSR is implemented.
RULE 2: If a scounteren bit is implemented as read-only zero, an attempted write of one to that bit leaves the bit zero.
RULE 3: Changing a bit in mcounteren does not change whether the corresponding bit in scounteren is writable.
RULE 4: When executing in M-mode or in S/HS-mode with V=0, a CSR access to scounteren is permitted subject to its WARL fields.
RULE 5: When executing in U-mode with V=0, an attempted CSR access to scounteren raises an illegal-instruction exception.
RULE 6: When executing in VS-mode, a CSR access to scounteren accesses the same scounteren state used to control VU-mode counter reads; no separate virtual-supervisor copy is selected.
RULE 7: When executing in VU-mode, an attempted CSR access to scounteren raises a virtual-instruction exception.
RULE 8: A counter read executed in S/HS-mode is not blocked by any scounteren bit.
RULE 9: A counter read executed in VS-mode is not blocked by any scounteren bit.
RULE 10: If scounteren.CY is zero, a U-mode read of cycle, or cycleh when XLEN=32, raises an illegal-instruction exception.
RULE 11: If scounteren.CY is one and mcounteren.CY is zero, a U-mode read of cycle, or cycleh when XLEN=32, raises an illegal-instruction exception.
RULE 12: If scounteren.CY and mcounteren.CY are both one, a U-mode read of cycle, or cycleh when XLEN=32, is permitted.
RULE 13: If scounteren.TM is zero, a U-mode read of time, or timeh when XLEN=32, raises an illegal-instruction exception.
RULE 14: If scounteren.TM is one and mcounteren.TM is zero, a U-mode read of time, or timeh when XLEN=32, raises an illegal-instruction exception.
RULE 15: If scounteren.TM and mcounteren.TM are both one, a U-mode read of time, or timeh when XLEN=32, is permitted.
RULE 16: If scounteren.IR is zero, a U-mode read of instret, or instreth when XLEN=32, raises an illegal-instruction exception.
RULE 17: If scounteren.IR is one and mcounteren.IR is zero, a U-mode read of instret, or instreth when XLEN=32, raises an illegal-instruction exception.
RULE 18: If scounteren.IR and mcounteren.IR are both one, a U-mode read of instret, or instreth when XLEN=32, is permitted.
RULE 19: For any n from 3 through 31, if scounteren.HPMn is zero, a U-mode read of hpmcountern, or hpmcounternh when XLEN=32, raises an illegal-instruction exception.
RULE 20: For any n from 3 through 31, if scounteren.HPMn is one and mcounteren.HPMn is zero, a U-mode read of hpmcountern, or hpmcounternh when XLEN=32, raises an illegal-instruction exception.
RULE 21: For any n from 3 through 31, if scounteren.HPMn and mcounteren.HPMn are both one, a U-mode read of hpmcountern, or hpmcounternh when XLEN=32, is permitted.
RULE 22: If mcounteren.CY is zero, a VU-mode read of cycle, or cycleh when XLEN=32, raises an illegal-instruction exception regardless of scounteren.CY and hcounteren.CY.
RULE 23: If mcounteren.CY is one and scounteren.CY is zero, a VU-mode read of cycle, or cycleh when XLEN=32, raises a virtual-instruction exception.
RULE 24: If mcounteren.CY and scounteren.CY are one and hcounteren.CY is zero, a VU-mode read of cycle, or cycleh when XLEN=32, raises a virtual-instruction exception.
RULE 25: If mcounteren.CY, scounteren.CY, and hcounteren.CY are all one, a VU-mode read of cycle, or cycleh when XLEN=32, is permitted.
RULE 26: If mcounteren.TM is zero, a VU-mode read of time, or timeh when XLEN=32, raises an illegal-instruction exception regardless of scounteren.TM and hcounteren.TM.
RULE 27: If mcounteren.TM is one and scounteren.TM is zero, a VU-mode read of time, or timeh when XLEN=32, raises a virtual-instruction exception.

RULE 31: If mcounteren.IR is one and scounteren.IR is zero, a VU-mode read of instret, or instreth when XLEN=32, raises a virtual-instruction exception.
