RULE 1: VLE32FF.V MUST execute as a regular load except that it will only take a trap caused by a synchronous exception on element 0.
RULE 2: If element 0 raises an exception during VLE32FF.V, the trap is taken and vl MUST NOT be modified.
RULE 3: If any element greater than 0 raises an exception during VLE32FF.V, the trap MUST NOT be taken and vl MUST be reduced to the index of that element.
RULE 4: VLE32FF.V MUST access non-idempotent memory locations only when it is known that the corresponding element load operation will not be restarted due to a trap or vector-length trimming.
RULE 5: If vstart = 0 and vl > 0 for VLE32FF.V, then at least one element MUST be processed.
