RULE 1: If mseccfg.MML is set to 1 and a PMP rule is configured with L=0, R=0, W=0, and X=0, access to the memory region is inaccessible, resulting in an Access Exception for both MMode and S/U Mode.
RULE 2: If mseccfg.MML is set to 1 and a PMP rule is configured with L=0, R=0, W=0, and X=1, access to the memory region results in an Access Exception for MMode, but grants execute-only access for S/U Mode.
RULE 3: If mseccfg.MML is set to 1 and a PMP rule is configured with L=0, R=0, W=1, and X=0, access to the memory region allows read/write on MMode and read-only on S/U Mode.
RULE 4: If mseccfg.MML is set to 1 and a PMP rule is configured with L=0, R=0, W=1, and X=1, access to the memory region allows read/write for both MMode and S/U Mode.
RULE 5: If mseccfg.MML is set to 1 and a PMP rule is configured with L=0, R=1, W=0, and X=0, access to the memory region is inaccessible, resulting in an Access Exception for both MMode and S/U Mode.
RULE 6: If mseccfg.MML is set to 1 and a PMP rule is configured with L=0, R=1, W=0, and X=1, access to the memory region results in an Access Exception for MMode, but grants read/execute access for S/U Mode.
RULE 7: If mseccfg.MML is set to 1 and a PMP rule is configured with L=0, R=1, W=1, and X=0, access to the memory region results in an Access Exception for MMode, but allows read/write on S/U Mode.
RULE 8: If mseccfg.MML is set to 1 and a PMP rule is configured with L=0, R=1, W=1, and X=1, access to the memory region allows read/write/execute for both MMode and S/U Mode.
RULE 9: If mseccfg.MML is set to 1 and a PMP rule is configured with L=1, R=0, W=0, and X=0, access to the memory region results in a Locked inaccessible region* exception for both MMode and S/U Mode.
RULE 10: If mseccfg.MML is set to 1 and a PMP rule is configured with L=1, R=0, W=0, and X=1, access to the memory region results in a Locked Execute-only region* exception for MMode, but results in an Access Exception for S/U Mode.
RULE 11: If mseccfg.MML is set to 1 and a PMP rule is configured with L=1, R=0, W=1, and X=0, access to the memory region results in a Locked Shared code region: Execute only on both MMode and S/U Mode* exception.
RULE 12: If mseccfg.MML is set to 1 and a PMP rule is configured with L=1, R=0, W=1, and X=1, access to the memory region results in a Locked Shared code region: Execute only on S/U Mode, read/execute on MMode* exception.
RULE 13: If mseccfg.MML is set to 1 and a PMP rule is configured with L=1, R=1, W=0, and X=0, access to the memory region results in a Locked Read-only region* exception for both MMode and S/U Mode.
RULE 14: If mseccfg.MML is set to 1 and a PMP rule is configured with L=1, R=1, W=0, and X=1, access to the memory region results in a Locked Read/Execute region* exception for both MMode and S/U Mode.
RULE 15: If mseccfg.MML is set to 1 and a PMP rule is configured with L=1, R=1, W=1, and X=0, access to the memory region results in a Locked Read/Write region* exception for both MMode and S/U Mode.
RULE 16: If mseccfg.MML is set to 1 and a PMP rule is configured with L=1, R=1, W=1, and X=1, access to the memory region results in a Locked Shared data region: Read only on both MMode and S/U Mode* exception.
