RULE 1: A write operation is mandated on the seed CSR upon reading to ensure the side effect of flushing the secret entropy bits occurs.
RULE 2: Hardware must implement wipe-on-read on the randomness pathway during each successful poll.
RULE 3: Only complete and fully processed random words shall be made available via entropy status (ES16 of seed).
RULE 4: When NOISE_TEST is set to 1 in mnoise, the seed CSR must not return anything via ES16.
RULE 5: When NOISE_TEST is set to 1 in mnoise, the seed CSR must be in the BIST state unless the source is in the DEAD state.
RULE 6: When NOISE_TEST is disabled, the entropy source shall return from the BIST state via an appropriate zeroization and self-test mechanism.
RULE 7: When NOISE_TEST is in mode, the WAIT and ES16 states are unreachable, and no entropy is output.
