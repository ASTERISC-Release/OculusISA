RULE 1: If a stateen CSR prevents access to state by less-privileged levels, an attempt in a less-privileged mode to read or write the protected state raises an illegal-instruction exception.
RULE 2: If a stateen CSR prevents access to state by less-privileged levels, an attempt from VS-mode or VU-mode to read or write the protected state raises a virtual-instruction exception.
RULE 3: If `mstateen0[60]` is 1 and `hstateen0[60]` is 0, all attempts from VS-mode or VU-mode to access `siselect` or `sireg*` raise a virtual-instruction exception.
RULE 4: If `menvcfg.CDE` is 1 and `mcounteren[i]` is 1, M-mode can delegate counter i to S-mode.
RULE 5: If `menvcfg.CDE` is 1 and `mcounteren[i]` is 1, the register state associated with counter i can be read or written via `sireg*` when `siselect` holds `0x40+i`.
