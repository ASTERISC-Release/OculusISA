RULE 1: When mstatus.VS is set to Off, attempting to execute any vector instruction or access the vector CSRs raises an illegal-instruction exception.
RULE 2: When mstatus.VS is set to Initial or Clean and a vector state change occurs, mstatus.VS changes to Dirty.
RULE 3: When mstatus.VS is set to Initial or Clean, mstatus.VS may change to Dirty even when there is no change in vector state.
RULE 4: When mstatus.VS is Dirty, mstatus.SD is 1.
RULE 5: When mstatus.VS is not Dirty, mstatus.SD is set in accordance with existing specifications.
