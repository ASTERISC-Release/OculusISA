RULE 1: When the TVM bit is set to 1, attempts to read or write the satp CSR while executing in S-mode will raise an illegal-instruction exception.
RULE 2: When the TVM bit is set to 1, attempts to execute the SFENCE.VMA instruction will raise an illegal-instruction exception.
RULE 3: When the TVM bit is set to 1, attempts to execute the SINVAL.VMA instruction will raise an illegal-instruction exception.
RULE 4: When the TVM bit is set to 0, attempts to read or write the satp CSR while executing in S-mode are permitted.
RULE 5: When the TVM bit is set to 0, attempts to execute the SFENCE.VMA instruction while executing in S-mode are permitted.
RULE 6: When the TVM bit is set to 0, attempts to execute the SINVAL.VMA instruction while executing in S-mode are permitted.
RULE 7: The TVM bit is read-only 0 when S-mode is not supported.
