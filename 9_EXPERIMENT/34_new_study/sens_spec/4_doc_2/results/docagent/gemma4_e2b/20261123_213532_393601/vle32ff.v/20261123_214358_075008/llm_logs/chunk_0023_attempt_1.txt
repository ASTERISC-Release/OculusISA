RULE 1: When V=1, instructions that normally read or modify a supervisor CSR shall instead access the corresponding VS CSR.
RULE 2: When V=1, an attempt to read or write a VS CSR directly by its own separate CSR address causes a virtual-instruction exception.
RULE 3: When V=1, both vsstatus .FS and the HS-level sstatus .FS are in effect.
RULE 4: When V=1, attempts to execute a floating-point instruction when either vsstatus .FS or sstatus .FS is 0 (Off) raise an illegal-instruction exception.
RULE 5: When V=1, modifying the floating-point state causes both vsstatus .FS and sstatus .FS to be set to 3 (Dirty).
RULE 6: When V=1, vsip and vsie substitute for sip and sie, so instructions that normally read or modify sip / sie actually access vsip / vsie instead.
RULE 7: When V=1, interrupts directed to HS-level continue to be indicated in the HS-level sip register, not in vsip.
RULE 8: When V=1, vstvec substitutes for the usual stvec, so instructions that normally read or modify stvec actually access vstvec instead.
RULE 9: When V=1, vsip and vsie are VS-mode's versions of sip and sie.
RULE 10: When V=1, vsip .LCOFIP and vsie .LCOFIE are aliases of sip .LCOFIP and sie .LCOFIE if the Shlcofideleg extension is implemented and hideleg bit 13 is writable.
RULE 11: When V=1, vsip .SEIP and vsie .SEIE are aliases of hip .VSEIP and hie .VSEIE if hideleg bit 10 is zero.
RULE 12: When V=1, vsip .STIP and vsie .STIE are aliases of hip .VSTIP and hie .VSTIE if hideleg bit 6 is zero.
RULE 13: When V=1, vsip .SSIP and vsie .SSIE are aliases of hip .VSSIP and hie .VSSIE if hideleg bit 2 is zero.
RULE 14: When V=1, reading the time CSR in VS or VU mode returns the sum of the contents of htimedelta and the actual value of time.
RULE 15: When V=1, access to the vstimecmp register (via stimecmp) is permitted in VS-mode only if the TM bit in hcounteren and the TM bit in mcounteren are both set.
RULE 16: When V=1, the hgatp register controls G-stage address translation and protection for guest virtual addresses.
RULE 17: When V=1, a write to hgatp does not imply any ordering constraints between page-table updates and subsequent G-stage address translations.
RULE 18: When V=1, the hgatp register is considered active for the purposes of the address-translation algorithm unless the effective privilege mode is U and hstatus .HU=0.
RULE 19: When V=1, vsepc substitutes for the usual sepc, so instructions that normally read or modify sepc actually access vsepc instead.
RULE 20: When V=1, vscause substitutes for the usual scause, so instructions that normally read or modify scause actually access vscause instead.
RULE 21: When V=1, vscause is a WLRL register that must be able to hold the same set of values that scause can hold.
RULE 22: When V=1, vsscratch substitutes for the usual sscratch, so instructions that normally read or modify sscratch actually access vsscratch instead.
