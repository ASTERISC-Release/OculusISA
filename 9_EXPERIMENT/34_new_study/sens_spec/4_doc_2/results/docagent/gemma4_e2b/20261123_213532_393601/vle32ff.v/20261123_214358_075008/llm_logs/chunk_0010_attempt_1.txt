RULE 1: When an instruction is encoded as masked (vm=0), vector merge instructions combine the first operand to the destination element if the mask value is zero, otherwise they copy the second operand to the destination element.
RULE 2: When an instruction is encoded as masked (vm=0), vector integer add/subtract instructions operate on and write back all body elements.
RULE 3: When an instruction is encoded as masked (vm=0), vector integer multiply-add instructions operate on and write back all body elements.
RULE 4: Vector integer move instructions are encoded as unmasked instructions (vm=1).
RULE 5: Vector integer move instructions copy a source operand to a vector register group.
RULE 6: Vector integer move instructions splat a scalar register or immediate to all active elements of the destination vector register group.
RULE 7: Vector integer compare instructions write 1 to the destination mask register element if the comparison evaluates to true, and 0 otherwise.
RULE 8: Vector floating-point compare instructions raise the invalid operation exception only on signaling NaN inputs.
RULE 9: Vector floating-point compare instructions raise the invalid operation exception on both signaling and quiet NaN inputs.
RULE 10: Vector floating-point instructions that modify any floating-point extension state must set mstatus.FS to Dirty.
RULE 11: Vector single-width saturating add and subtract instructions set the vxsat bit if the result would overflow the destination.
RULE 12: Vector averaging add and subtract instructions ignore overflow for subtraction and the result wraps around.
RULE 13: Vector single-width fractional multiply instructions set the vxsat bit if the result causes saturation.
RULE 14: Vector single-width scaling shift instructions round off the shifted out bits according to the vxrm CSR.
RULE 15: Vector narrowing clip instructions use the rounding mode specified in the vxrm CSR.
RULE 16: When performing a narrowing unsigned clip, the shifted rounded source value is treated as an unsigned integer and saturates if the result would overflow the destination viewed as an unsigned integer.
RULE 17: When performing a narrowing signed clip, the shifted rounded source value is treated as a signed integer and saturates if the result would overflow the destination viewed as a signed integer.
RULE 18: Vector ordered single-width floating-point sum reduction performs the computation: vd[0] = (((vs1[0] + vs2[0]) + vs2[1]) + ...) + vs2[vl-1].
RULE 19: When performing a masked ordered floating-point sum reduction, masked-off elements do not affect the result or the exception flags.
RULE 20: When performing an unordered single-width floating-point sum reduction, the implementation computes an exact sum using infinite precision before converting to a floating-point format.
RULE 21: When performing an unordered single-width floating-point sum reduction, the reduction tree structure must be deterministic for a given value in vtype and vl.
RULE 22: When performing an unordered single-width floating-point sum reduction, the additive identity is +0.0 when rounding down (towards -∞) or -0.0 for all other rounding modes.
RULE 23: Vector widening integer reduction instructions perform overflows by wrapping around.
RULE 24: Vector widening unsigned integer reduction instructions zero-extend the SEW-wide vector elements before summing them and add the 2*SEW-width scalar element, storing the result in a 2*SEW-width scalar element.
RULE 25: Vector widening signed integer reduction instructions sign-extend the SEW-wide vector elements before summing them and add the 2*SEW-width scalar element, storing the result in a 2*SEW-width scalar element.
RULE 26: Vector widening floating-point reduction instructions perform the SEW-width element reduction as in the single-width case, with elements in vs2 promoted to 2*SEW bits before adding to the 2*SEW-bit accumulator.
