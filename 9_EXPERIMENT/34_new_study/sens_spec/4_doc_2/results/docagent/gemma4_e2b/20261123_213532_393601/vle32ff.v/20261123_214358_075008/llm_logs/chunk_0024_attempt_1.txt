RULE 1: When a virtual-machine load/store instruction is executed, it is valid only in M-mode or HS-mode, or in Umode when hstatus.HU=1.
RULE 2: When a virtual-machine load/store instruction is executed, the effective privilege mode is VU when hstatus.SPVP=0, and VS when hstatus.SPVP=1.
RULE 3: When a virtual-machine load/store instruction is executed, two-stage address translation is applied, involving VS-stage and G-stage translation.
RULE 4: When a virtual-machine load/store instruction is executed, the effective privilege mode is VU when hstatus.SPVP=0, and VS when hstatus.SPVP=1.
RULE 5: When a virtual-machine load/store instruction is executed, the effective privilege mode is VU when hstatus.SPVP=0, and VS when hstatus.SPVP=1.
RULE 6: When a virtual-machine load/store instruction is executed, execution requires the memory to be executable in both VS-stage and G-stage address translation.
RULE 7: When a virtual-machine load/store instruction is executed, attempting to execute it when V=1 causes a virtual-instruction exception.
RULE 8: When a virtual-machine load/store instruction is executed from U-mode when hstatus.HU=0, it causes an illegal-instruction exception.
RULE 9: When a virtual-machine load/store instruction is executed, attempts to execute it cannot override machine-level physical memory protection (PMP).
RULE 10: Memory accesses performed by virtual-machine load/store instructions are not subject to pointer masking.
