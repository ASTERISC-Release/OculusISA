RULE 1: mseccfg exists if any extension that adds a field to mseccfg is implemented; otherwise, it is reserved.
RULE 2: If mseccfg.USEED is 0, access to the seed CSR in U-mode raises an illegal-instruction exception.
RULE 3: If mseccfg.USEED is 1, read-write access to the seed CSR from U-mode is allowed, and all other types of accesses raise an illegal-instruction exception.
RULE 4: If Zkr or U-mode is not implemented, mseccfg.USEED is read-only zero.
RULE 5: If mseccfg.SSEED is 0, access to the seed CSR from S-/HS-mode raises an illegal-instruction exception.
RULE 6: If mseccfg.SSEED is 1, read-write access to the seed CSR from S-/HS-mode is allowed, and all other types of accesses raise an illegal-instruction exception.
RULE 7: If Zkr or S-mode is not implemented, mseccfg.SSEED is read-only zero.
RULE 8: If the H extension is implemented, access to the seed CSR from an HS-qualified instruction leads to a virtual-instruction exception in VS and VU modes; all other types of accesses raise an illegal-instruction exception.
RULE 9: When mseccfg.RLB is 1, locked PMP rules may be removed or modified and locked PMP rules may be edited.
RULE 10: When mseccfg.RLB is 0 and pmpcfg.L is 1 in any rule or entry, mseccfg.RLB remains 0 and any further modifications to mseccfg.RLB are ignored until a PMP reset.
RULE 11: When mseccfg.MMWP is set, the default PMP policy for M-mode when accessing memory regions that don't have a matching PMP rule changes to denied instead of ignored.
RULE 12: mseccfg.MMWP is a sticky bit, meaning that once set it cannot be unset until a PMP reset.
RULE 13: When mseccfg.MML is set, the meaning of pmpcfg.L changes: a rule is marked as M-mode-only when set and S/U-mode-only when unset, or a Shared-Region rule is enforced.
RULE 14: mseccfg.MML is a sticky bit, meaning that once set it cannot be unset until a PMP reset.
RULE 15: If Smmpm is not implemented, the PMM field is read-only zero.
RULE 16: When mseccfg.MLPE is 1, the Zicfilp extension is enabled in M-mode.
RULE 17: When mseccfg.MLPE is 0, the Zicfilp extension is not enabled in M-mode.
RULE 18: When XLEN=32, mseccfgh is a 32-bit read/write register that aliases bits 63:32 of mseccfg.
RULE 19: The register mseccfgh does not exist when XLEN=64.
