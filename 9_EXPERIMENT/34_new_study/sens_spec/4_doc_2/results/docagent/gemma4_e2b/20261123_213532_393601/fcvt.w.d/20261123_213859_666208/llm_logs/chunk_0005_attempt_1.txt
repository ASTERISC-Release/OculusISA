RULE 1: When FCVT.W.D is executed, it converts a double-precision floating-point number in floating-point register rs1 to a signed 32-bit integer in integer register rd.
RULE 2: When FCVT.D.W is executed, it converts a signed 32-bit integer in integer register rs1 to a double-precision floating-point number in floating-point register rd.
RULE 3: When FCVT.L.D is executed, it converts a double-precision floating-point number in floating-point register rs1 to a 64-bit integer in integer register rd.
RULE 4: When FCVT.D.L is executed, it converts a signed 64-bit integer in integer register rs1 to a double-precision floating-point number in floating-point register rd.
RULE 5: When FCVT.W[U].D is executed on RV64, it sign-extends the 32-bit result when converting a 32-bit integer in rs1 to a double-precision floating-point number in rd.
RULE 6: All floating-point to integer and integer to floating-point conversion instructions round according to the rm field.
RULE 7: When FCVT.D.W[U] is executed, the result is exact and is unaffected by the rounding mode.
RULE 8: When FCVT.WU.D, FCVT.LU.D, FCVT.D.WU, or FCVT.D.LU are executed, they convert to or from unsigned integer values.
