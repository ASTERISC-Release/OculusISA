RULE 1: Attempting to read or write hgatp while executing in HS-mode raises an illegal-instruction exception if mstatus .TVM is set to 1.
RULE 2: Fields VTSR, VTW, and VTVM in hstatus affect execution only in VS-mode and cause virtual-instruction exceptions instead of illegal-instruction exceptions.
RULE 3: When V=1, modifying the floating-point state (vsstatus .FS or HS-level sstatus .FS) causes both fields to be set to 3 (Dirty).
RULE 4: When V=1, modifying the vector state (vsstatus .VS or HS-level sstatus .VS) causes both fields to be set to 3 (Dirty).
RULE 5: When V=1, attempting to read or write a VS CSR directly by its own separate CSR address causes a virtual-instruction exception.
