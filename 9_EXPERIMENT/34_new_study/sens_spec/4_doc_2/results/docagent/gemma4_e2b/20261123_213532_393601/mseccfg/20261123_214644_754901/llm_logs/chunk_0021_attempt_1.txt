RULE 1: When Smcdeleg/Ssccfg extensions are enabled (`menvcfg.CDE=1`) and a counter $i$ is delegated (`mcounteren[i]=1`), the register state associated with counter $i$ can be read or written via sireg* when siselect holds $0x40+i$.
RULE 2: If the Smcdeleg/Ssccfg extensions are enabled (`menvcfg.CDE=1`) and Sscofpmf is implemented, the event selector bit 62 (MINH) is read-only 0 when accessed through sireg*.
RULE 3: If the Smcdeleg/Ssccfg extensions are enabled (`menvcfg.CDE=1`) and Smcntrpmf is implemented, the counter configuration register bit 62 (MINH) is read-only 0 when accessed through sireg*.
RULE 4: If a local-counter-overflow interrupt (LCOFI) traps to M-mode or S-mode, sctrstatus.FROZEN is set by hardware.
RULE 5: When $menvcfg.CDE=0$, attempts to access scountinhibit raise an illegal-instruction exception.
RULE 6: When Supervisor Counter Delegation is enabled, attempts to access scountinhibit from VS-mode or VU-mode raise a virtual-instruction exception.
RULE 7: If implementations support Smcdeleg/Ssccfg, Sscofpmf, and the H extension, attempts to read scountovf from VS-mode or VU-mode raise a virtual-instruction exception when $menvcfg.CDE=1$.
RULE 8: If implementations support Smcdeleg/Ssccfg, Sscofpmf, Smaia/Ssaia, and the H extension, the LCOFI bit (bit 13) in hvip and hvien is implemented and writable.
RULE 9: While siselect holds a value in the range 0x40-0x5F, an attempt to access any vsireg* from M or S mode raises an illegal-instruction exception.
RULE 10: While siselect holds a value in the range 0x40-0x5F, an attempt from VS-mode to access any vsireg* (really vsiselect) raises an illegal-instruction exception if $menvcfg.CDE=0$.
RULE 11: While siselect holds a value in the range 0x40-0x5F, an attempt from VS-mode to access any vsireg* (really vsiselect) raises a virtual-instruction exception if $menvcfg.CDE=1$.
RULE 12: When mstateen0.CTR=0 and the privilege mode is less privileged than M-mode, attempts to access sctrctl, vsctrctl, sctrdepth, or sctrstatus raise an illegal-instruction exception.
RULE 13: When mstateen0.CTR=0 and the privilege mode is less privileged than M-mode, attempts to access sireg* when siselect is in 0x200..0x2FF raise an illegal-instruction exception.
RULE 14: When mstateen0.CTR=0 and the privilege mode is less privileged than M-mode, attempts to access vsireg* when vsiselect is in 0x200..0x2FF raise an illegal-instruction exception.
RULE 15: When mstateen0.CTR=0, execution of the SCTRCLR instruction raises an illegal-instruction exception if the privilege mode is less privileged than M-mode.
RULE 16: When mstateen0.CTR=1 and hstateen0.CTR=1, VS-mode accesses to supervisor CTR state behave as described in Section 7.2 and Section 11.2.
RULE 17: When mstateen0.CTR=1 and hstateen0.CTR=0, VS-mode accesses to supervisor CTR state and execution of SCTRCLR raise a virtual-instruction exception.
RULE 18: When hstateen0.CTR=0, qualified control transfers executed while V=1 will continue to implicitly update entry registers and sctrstatus.
RULE 19: When mstateen0.CTR=1 and hstateen0.CTR=1, VS-mode accesses to supervisor CTR state behave as described in Section 7.2 and Section 11.2.
RULE 20: When hstateen0.CTR=1, VS-mode accesses to supervisor CTR state behave as described in Section 7.2 and Section 11.2.
