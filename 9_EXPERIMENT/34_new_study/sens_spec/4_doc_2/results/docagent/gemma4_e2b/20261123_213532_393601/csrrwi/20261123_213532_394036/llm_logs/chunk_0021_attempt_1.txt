RULE 1: When the current privilege mode is enabled for recording and the transfer type is not inhibited and sctrstatus .FROZEN is not set, a control transfer is qualified.
RULE 2: Qualified control transfers update the Entry Registers at logical entry 0.
RULE 3: If the CTR buffer is full, the oldest recorded entry is lost.
RULE 4: Recorded transfers set the ctrsource .V bit to 1 and update all implemented record fields.
RULE 5: The SCTRCLR instruction zeroes all CTR Entry Registers, the CTR cycle counter, and the Cycle Count Valid (CCV) bit.
RULE 6: SCTRCLR raises an illegal-instruction exception in U-mode, and a virtual-instruction exception in VUmode, unless CTR state enable access restrictions apply.
RULE 7: When mstateen0 .CTR is 0 and the privilege mode is less privileged than M-mode, attempts to access sctrctl, vsctrctl, sctrdepth, sctrstatus, sireg* when siselect is in 0x200..0x2FF, or vsireg* when vsiselect is in 0x200..0x2FF, or execution of the SCTRCLR instruction raise an illegal-instruction exception.
RULE 8: When mstateen0 .CTR is 1 and hstateen0 .CTR is 1, VS-mode accesses to supervisor CTR state behave as described in Section 7.2 and Section 11.2.
RULE 9: When mstateen0 .CTR is 1 and hstateen0 .CTR is 0, VS-mode accesses to supervisor CTR state and VSmode execution of SCTRCLR raise a virtual-instruction exception.
RULE 10: If the H extension is implemented, when mstateen0 .CTR is 1 and hstateen0 .CTR is 1, hstateen0 .CTR controls access to supervisor CTR state when V=1.
RULE 11: When sctrstatus .FROZEN is set, transfer recording is inhibited.
RULE 12: When sctrctl .LCOFIFRZ is 1 and a local-counter-overflow interrupt traps to M-mode or to S-mode, sctrstatus .FROZEN is set by hardware.
RULE 13: When sctrctl .BPFRZ is 1 and a breakpoint exception traps to M-mode or S-mode, sctrstatus .FROZEN is set by hardware.
RULE 14: When the H extension is implemented, freeze behavior for LCOFIs and breakpoint exceptions that trap to VSmode is determined by the LCOFIFRZ and BPFRZ values in vsctrctl.
RULE 15: When an external trap is recorded, the ctrtarget .PC is 0.
RULE 16: External trap recording depends on the external trap enable bits for the target mode and all intervening modes being enabled for recording.
RULE 17: When an external trap is recorded, the ctrtarget .PC is 0.
RULE 18: If an external trap is recorded, the ctrtarget .PC is 0.
RULE 19: If sctrctl .STE is set, U-mode can opt-in to record traps to S-mode.
RULE 20: If mctrctl .MTE and sctrctl .STE are implemented, U-mode can opt-in to record external traps to M-mode.
RULE 21: If mctrctl .MTE, sctrctl .STE, and vsctrctl .STE are implemented, VS-mode can opt-in to record external traps to M-mode.
RULE 22: When mstateen0 .CTR is 0 and the privilege mode is less privileged than M-mode, attempts to access sireg* when siselect is in 0x200..0x2FF raise an illegal-instruction exception.
RULE 23: When mstateen0 .CTR is 0 and the privilege mode is less privileged than M-mode, attempts to access vsireg* when vsiselect is in 0x200..0x2FF raise an illegal-instruction exception.
RULE 24: When siselect holds a value in the range 0x40-0x5F and a counter i is delegated (mcounteren [ i ]=1 and menvcfg .CDE=1), the register state associated with counter i can be read or written via sireg*, while siselect holds 0x40+ i.
RULE 25: If any extension upon which the underlying state for a specific siselect and sireg* combination depends is not implemented, an attempt from M or S mode to access the given state through sireg* raises an illegal-instruction exception.
RULE 26: If any extension upon which the underlying state for a specific siselect and sireg* combination depends is not implemented, an attempt from M or S mode to access the given state through sireg* raises an illegal-instruction exception.
RULE 27: If the H extension is implemented, attempts from VS-mode to access any sireg* (really vsireg*) raises an illegal-instruction exception if menvcfg .CDE = 0, or a virtual-instruction exception if menvcfg .CDE = 1.
RULE 28: If an implementation of any transfer type filter bit results in reduced software performance, it is recommended that this reduced performance applies only when the bit is set.
RULE 29: When CtrCycleCounter is incremented, the CC field is encoded such that CCE holds 0 if the CtrCycleCounter value is less than 4096.
RULE 30: The elapsed cycle count can be calculated by software using the formula if (CCE==0): return CCM else: return (2 12 + CCM) << CCE-1 endif.
RULE 31: The CtrCycleCounter is reset on writes to x ctrctl, and on execution of SCTRCLR.
RULE 32: Attempts to access sctrdepth from VS-mode or VU-mode raise a virtual-instruction exception, unless CTR state enable access restrictions apply.
