RULE 1: If a hart is running at a privilege level that does not permit access to a specified CSR according to Table 3, the instruction causes an illegal-instruction exception or a virtual-instruction exception.
RULE 2: If an attempt is made to write to a CSR marked as read-only according to Table 3, the instruction causes an illegal-instruction exception.
RULE 3: If an attempt is made to access a CSR address that does not exist, the instruction causes an illegal-instruction exception.
RULE 4: A read operation to a CSR does not cause any architectural state side effects.
RULE 5: A write operation to a CSR causes an architectural state side effect on that CSR.
