RULE 1: If the application vector length (AVL) is less than or equal to the maximum vector length (VLMAX), the resulting vector length (vl) is set to AVL.
RULE 2: If the application vector length (AVL) is less than (2 * VLMAX), the resulting vector length (vl) is set such that ceil(AVL / 2) is less than or equal to vl, and vl is less than or equal to VLMAX.
RULE 3: If the application vector length (AVL) is greater than or equal to (2 * VLMAX), the resulting vector length (vl) is set to VLMAX.
RULE 4: The setting of vl is deterministic for a given implementation for the same input AVL and VLMAX values.
RULE 5: If AVL is 0, the resulting vector length (vl) is 0.
RULE 6: If AVL is greater than 0, the resulting vector length (vl) is greater than 0.
RULE 7: The resulting vector length (vl) is less than or equal to VLMAX.
RULE 8: If the vtype value is not supported by the implementation, the vill bit is set in vtype, the remaining bits in vtype are set to zero, and the vl register is set to zero.
RULE 9: A vtype value with the vill bit set is treated as an unsupported configuration.
RULE 10: For the vsetivli instruction, the AVL is encoded as a 5-bit zero-extended immediate (0-31) in the rs1 field.
