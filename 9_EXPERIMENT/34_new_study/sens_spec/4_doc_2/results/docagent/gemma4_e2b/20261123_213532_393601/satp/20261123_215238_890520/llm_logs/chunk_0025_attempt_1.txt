RULE 1: If Pointer Masking is enabled, the pointer masking setting applied is determined by the active privilege mode and configuration registers of the next-higher privilege mode.
RULE 2: When an address translation mode is not Bare, the ignore transformation applied to a physical address replaces the upper PMLEN bits with zero.
RULE 3: When Pointer Masking is enabled, the ignore transformation is applied to every explicit memory access, including loads/stores, atomics operations, and floating point loads/stores.
RULE 4: When the active `satp` register's MODE field is not Bare, the ignore transformation applied to a physical address replaces the upper PMLEN bits with zero.
