RULE 1: When executing VLE32FF.V, masked-off elements never generate exceptions.
RULE 2: When executing VLE32FF.V, destination elements corresponding to masked-off elements are handled with either a mask-undisturbed or mask-agnostic policy depending on the setting of vtype.vma.
RULE 3: When executing VLE32FF.V with unit-stride addressing, the effective vector length is evl = ceil(vl /8), and the destination register is always written with a tail-agnostic policy.
RULE 4: When executing VLE32FF.V with unit-stride addressing and fault-only-first mode, the instruction only takes a trap caused by a synchronous exception on element 0.
RULE 5: When executing VLE32FF.V with unit-stride addressing and fault-only-first mode, if an element greater than 0 raises an exception, the corresponding trap is not taken, and the vector length vl is reduced to the index of the element that would have raised an exception.
RULE 6: When executing VLE32FF.V, the element width is 32 bits, and the memory access size is 32 bits.
