RULE 1: When S-mode is implemented, xLPE is determined by mseccfg.MLPE when in M-mode.
RULE 2: When S-mode is implemented, xLPE is determined by menvcfg.LPE when in S-mode or HS-mode.
RULE 3: When S-mode is implemented, xLPE is determined by henvcfg.LPE when in VS-mode.
RULE 4: When S-mode is implemented, xLPE is determined by senvcfg.LPE when in U-mode or VU-mode.
RULE 5: When S-mode is not implemented, xLPE is determined by menvcfg.LPE when in M-mode.
RULE 6: When S-mode is not implemented, xLPE is determined by menvcfg.LPE when in U-mode.
RULE 7: The Zicfilp must be explicitly enabled for use at each privilege mode.
RULE 8: Programs compiled with the LPAD instruction continue to function correctly but without forward-edge CFI protection when the Zicfilp extension is not implemented or is not enabled.
