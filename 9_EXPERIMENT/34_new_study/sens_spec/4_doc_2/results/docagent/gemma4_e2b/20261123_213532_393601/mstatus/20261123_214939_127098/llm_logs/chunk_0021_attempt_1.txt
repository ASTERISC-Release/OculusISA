RULE 1: Reading or writing any field in sstatus is equivalent to reading or writing the homonymous field in mstatus.
RULE 2: When MXR=0, loads from pages marked readable (R=1) will succeed.
RULE 3: When MXR=1, loads from pages marked readable (R=1) or executable (X=1) will succeed.
RULE 4: When SUM=0, S-mode memory accesses to pages accessible by U-mode (U=1) will fault.
RULE 5: When SUM=1, S-mode memory accesses to pages accessible by U-mode (U=1) will be permitted.
RULE 6: SUM has no effect when page-based virtual memory is not in effect or when executing in U-mode.
RULE 7: SUM is read-only 0 if satp .MODE is read-only 0.
RULE 8: When mstateen0 .CTR=0 and the privilege mode is less privileged than M-mode, attempts to access sctrctl, vsctrctl, sctrdepth, or sctrstatus raise an illegal-instruction exception.
RULE 9: When mstateen0 .CTR=0 and the privilege mode is less privileged than M-mode, attempts to access sireg* when siselect is in 0x200..0x2FF, or vsireg* when vsiselect is in 0x200..0x2FF raise an illegal-instruction exception.
RULE 10: When mstateen0 .CTR=0 and the privilege mode is less privileged than M-mode, execution of the SCTRCLR instruction raises an illegal-instruction exception.
RULE 11: When mstateen0 .CTR=1 and hstateen0 .CTR=1, VS-mode accesses to supervisor CTR state behave as described in Section 7.2 and Section 11.2, and SCTRCLR behaves as described in Section 11.3.1.
RULE 12: When mstateen0 .CTR=1 and hstateen0 .CTR=0, VS-mode accesses to supervisor CTR state and VSmode execution of SCTRCLR raise a virtual-instruction exception.
RULE 13: When mstateen0 .CTR=1 and hstateen0 .CTR=1, when VS-mode accesses to supervisor CTR state, they behave as described in Section 7.2 and Section 11.2.
RULE 14: When hstateen0 .CTR=0, qualified control transfers executed while V=1 will continue to implicitly update entry registers and sctrstatus.
RULE 15: When an interrupt traps to S-mode, the SPP bit is set to 0 if the trap originated from user mode, or 1 otherwise.
RULE 16: When an SRET instruction is executed from a trap handler, the SPP bit is set to user mode if it was 0, or supervisor mode if it was 1, and then SPP is set to 0.
RULE 17: When a trap is taken into supervisor mode, SPIE is set to SIE, and SIE is set to 0.
RULE 18: When an SRET instruction is executed, SIE is set to SPIE, and SPIE is set to 1.
RULE 19: An interrupt i traps to S-mode if both (a) the current privilege mode is S and the SIE bit in sstatus is set, or (b) the current privilege mode has less privilege than S-mode, and (c) bit i is set in both sip and sie.
RULE 20: Interrupts to S-mode take priority over any interrupts to lower privilege modes.
