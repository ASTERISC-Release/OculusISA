RULE 1: If rd is x0, the CSRRWI instruction does not read the CSR and does not cause any side effects that might occur on a CSR read.
RULE 2: If rd is not x0, the CSRRWI instruction reads the CSR and writes the CSR.
RULE 3: If uimm is zero, the CSRRWI instruction does not write to the CSR and does not cause any side effects that might otherwise occur on a CSR write.
RULE 4: If uimm is non-zero, the CSRRWI instruction reads the CSR and writes the CSR.
RULE 5: If an instruction is CSRRWI and the destination register is x0, the instruction does not carry a dependency from any source register to the destination register.
RULE 6: If the instruction CSRRWI executes and the destination register rd is not equal to x0, then rd carries a dependency from csr.
RULE 7: If the application vector length (AVL) is less than or equal to the maximum vector length (VLMAX), the resulting vector length (vl) is set to AVL.
RULE 8: If the application vector length (AVL) is less than (2 * VLMAX), the resulting vector length (vl) is set such that ceil(AVL / 2) is less than or equal to vl, and vl is less than or equal to VLMAX.
RULE 9: If the application vector length (AVL) is greater than or equal to (2 * VLMAX), the resulting vector length (vl) is set to VLMAX.
RULE 10: The setting of vl is deterministic for a given implementation for the same input AVL and VLMAX values.
RULE 11: If AVL is 0, the resulting vector length (vl) is 0.
RULE 12: If AVL is greater than 0, the resulting vector length (vl) is greater than 0.
RULE 13: The resulting vector length (vl) is less than or equal to VLMAX.
RULE 14: If the vtype value is not supported by the implementation, the vill bit is set in vtype, the remaining bits in vtype are set to zero, and the vl register is set to zero.
RULE 15: A vtype value with the vill bit set is treated as an unsupported configuration.
RULE 16: For the vsetivli instruction, the AVL is encoded as a 5-bit zero-extended immediate (0-31) in the rs1 field.
RULE 17: A write operation is mandated on the seed CSR upon reading to ensure the side effect of flushing the secret entropy bits occurs.
RULE 18: Hardware must implement wipe-on-read on the randomness pathway during each successful poll.
RULE 19: Only complete and fully processed random words shall be made available via entropy status (ES16 of seed).
RULE 20: When NOISE_TEST is set to 1 in mnoise, the seed CSR must not return anything via ES16.
