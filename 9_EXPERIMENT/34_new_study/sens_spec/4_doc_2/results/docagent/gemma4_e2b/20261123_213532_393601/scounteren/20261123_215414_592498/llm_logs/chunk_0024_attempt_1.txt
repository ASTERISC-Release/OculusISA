RULE 1: When in VS-mode, attempts to access a non-high-half counter CSR cause a virtual-instruction exception if scounteren is 0 and mcounteren is 1.
RULE 2: When in VS-mode and XLEN=32, attempts to access a high-half counter CSR cause a virtual-instruction exception if scounteren is 0 and hcounteren is 0 and mcounteren is 1.
RULE 3: When in VU-mode, attempts to access a non-high-half counter CSR cause a virtual-instruction exception if scounteren is 0 or hcounteren is 0 and mcounteren is 1.
RULE 4: When in VU-mode and XLEN=32, attempts to access a high-half counter CSR cause a virtual-instruction exception if scounteren is 0 or hcounteren is 0 and mcounteren is 1.
