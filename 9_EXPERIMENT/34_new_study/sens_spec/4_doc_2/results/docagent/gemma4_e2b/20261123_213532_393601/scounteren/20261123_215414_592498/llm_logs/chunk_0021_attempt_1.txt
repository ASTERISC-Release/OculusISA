RULE 1: When `mstateen0.CTR=0` and the privilege mode is less privileged than M-mode, attempts to access `sctrctl`, `vsctrctl`, `sctrdepth`, or `sctrstatus` raise an illegal-instruction exception.
RULE 2: When `mstateen0.CTR=0` and the privilege mode is less privileged than M-mode, attempts to access `sireg*` when `siselect` is in the range 0x200 through 0x2FF raise an illegal-instruction exception.
RULE 3: When `mstateen0.CTR=0` and the privilege mode is less privileged than M-mode, execution of the `SCTRCLR` instruction raises an illegal-instruction exception.
RULE 4: When Supervisor Counter Delegation is enabled and an attempt to access `scountinhibit` is made from VS-mode or VU-mode, a virtual-instruction exception is raised.
RULE 5: When counters are not delegated to S-mode, the bits in `scountinhibit` are read-only zero.
RULE 6: If implementations support Smcdeleg/Ssccfg, Sscofpmf, and the H extension, attempting to read `scountovf` from VS-mode or VU-mode raises a virtual-instruction exception when `menvcfg.CDE=1`.
RULE 7: If `mstateen0.CTR=1` and `hstateen0.CTR=0`, VS-mode accesses to supervisor CTR state or VSmode execution of `SCTRCLR` raise a virtual-instruction exception.
RULE 8: When `mstateen0.CTR=1` and `hstateen0.CTR=1`, VS-mode accesses to supervisor CTR state behave as described in Section 7.2 and Section 11.2.
RULE 9: If CTR is active (current privilege mode is enabled for recording and CTR is not frozen) and a qualified control transfer occurs, the Entry Registers are updated at logical entry 0, and `ctrsource.V` is set to 1.
RULE 10: If the CTR buffer is full, the oldest recorded entry is lost upon a qualified control transfer.
RULE 11: Execution of the `SCTRCLR` instruction zeroes all CTR Entry Registers for all DEPTH values.
RULE 12: Execution of the `SCTRCLR` instruction zeroes the CTR cycle counter and CCV.
RULE 13: A read of `ctrsource`, `ctrtarget`, or `ctrdata` following `SCTRCLR` but preceding the next qualified control transfer returns 0.
RULE 14: The first recorded transfer following `SCTRCLR` will have `ctrdata.CCV=0`.
RULE 15: When `sctrstatus.FROZEN=1`, transfer recording is inhibited.
RULE 16: If `sctrctl.LCOFIFRZ=1` and a local-counter-overflow interrupt (LCOFI) traps to M-mode or S-mode, `sctrstatus.FROZEN` is set by hardware.
RULE 17: If `sctrctl.BPFRZ=1` and a breakpoint exception traps to M-mode or S-mode, `sctrstatus.FROZEN` is set by hardware.
RULE 18: If CTR is active, the `CtrCycleCounter` increments at the same rate as the `mcycle` counter.
RULE 19: When CTR is active, the `CC` field is encoded such that CCE holds 0 if the `CtrCycleCounter` value is less than 4096, otherwise it holds the index of the most significant one bit in the `CtrCycleCounter` value, minus 11, and CCM holds `CtrCycleCounter` bits CCE+10:CCE-1.
RULE 20: Writing to `x ctrctl` or execution of `SCTRCLR` resets the `CtrCycleCounter`, ensuring accumulated cycle counts do not persist across a context switch.
