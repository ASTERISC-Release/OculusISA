RULE 1: If mstatus.FS is Off, any attempt to execute a vector floating-point instruction will raise an illegal-instruction exception.
RULE 2: If a vector floating-point instruction modifies any floating-point extension state (i.e., floating-point CSRs or f registers), mstatus.FS must be set to Dirty.
RULE 3: If vsstatus.FS is Off or mstatus.FS is Off, any attempt to execute a vector floating-point instruction will raise an illegal-instruction exception.
RULE 4: If a vector floating-point instruction modifies any floating-point extension state (i.e., floating-point CSRs or f registers), both mstatus.FS and vsstatus.FS must be set to Dirty.
