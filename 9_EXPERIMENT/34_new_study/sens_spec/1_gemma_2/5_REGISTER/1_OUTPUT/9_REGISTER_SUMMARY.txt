REGISTER: mseccfg
SUMMARY: The `mseccfg` register controls security features, access to the seed CSR, and physical memory protection rules. Access permissions, particularly for seed CSR access in Supervisor and User modes, are dictated by the SSEED and USEED fields, which can enable read-write access depending on the mode and field settings. The register also contains fields (MMWP, MML, RLB) that define complex shared-region rules and locked memory protection policies, allowing for secure sharing or enforcement of mode-specific access restrictions. Accessing the register is generally illegal in S-mode and U-mode, though M-mode access is typically permitted, and specific extensions like Zkr or Smepmp modify exception handling behavior.

REGISTER: mstatus
SUMMARY: The mstatus register governs privilege mode, memory access control, and vector/floating-point state. Memory access permissions are determined by the MPRV, MXR, and SUM fields, which control translation, protection, and access rules for page-based virtual memory, while the MBE, SBE, and UBE fields control memory endianness. The VS and FS fields track the vector and floating-point execution state, requiring the SD bit to be set if the state is Dirty. Vector operations are restricted by mstatus.VS, and vector floating-point operations modify mstatus.FS and vsstatus.FS to Dirty. Trap return instructions (MRET/MNRET) modify privilege mode and set specific control bits like MPV and MPP according to the trap origin.

REGISTER: satp
SUMMARY: The `satp` register is an SXLEN-bit read/write register that controls supervisor-mode address translation and protection, storing the physical page number of the root page table, a VMID, and the address translation mode (MODE). It operates at the Supervisor privilege level, and S-mode instruction fetches implicitly read this register, with translations only beginning when `satp` is active. Access and exception behavior are heavily dependent on the active privilege mode and specific bits such as TVM, ASIDLEN, and various page table implementation extensions. Specific instructions like SFENCE.VMA or SINVAL.VMA may cause illegal instruction exceptions based on the mode and the TVM status.

REGISTER: scounteren
SUMMARY: The scounteren register is protected, raising an Illegal Access exception in Non-Supervisor privilege levels. Access in U-mode is highly restricted, often requiring specific bits to be set and potentially resulting in illegal-instruction exceptions if read attempts are made under certain conditions. M-mode provides unrestricted access to the register. Furthermore, certain bits may function as read-only zero fields, causing exceptions in U-mode reads, and setting the HPM bits in M-mode is reflected on readback.
