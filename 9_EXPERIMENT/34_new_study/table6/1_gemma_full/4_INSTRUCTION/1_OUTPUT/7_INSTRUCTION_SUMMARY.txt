INSTRUCTION: CSRRWI
SUMMARY: The CSRRWI instruction updates a specified CSR with an XLEN-bit value derived from a zero-extended 5-bit unsigned immediate. If the destination register rd is not x0, it is updated with the CSR's original value; otherwise, the CSR is not read, avoiding associated read side effects. Regardless of the destination register, the write to the CSR always occurs and triggers any defined write side effects.

INSTRUCTION: FCVT.W.D
SUMMARY: FCVT.W.D converts a double-precision floating-point value from register rs1 to a signed 32-bit integer in register rd, rounding the result based on the rm field. On RV64 systems, the 32-bit result is sign-extended. If the input is outside the representable signed 32-bit integer range, the result follows the behavior of FCVT.int.S.

INSTRUCTION: SFENCE.VMA
SUMMARY: SFENCE.VMA uses the value in rs1 as a virtual address, though it has no effect if the address is invalid. Execution in U-mode, or in S-mode or HS-mode when TVM=1, raises an illegal-instruction exception. In S-mode with TVM=0, the instruction executes without exception. Execution in VU-mode, or in VS-mode when VTVM=1, raises a virtual-instruction exception.

INSTRUCTION: VLE32FF.V
SUMMARY: VLE32FF.V executes as a regular load that only takes synchronous exception traps caused by element 0. If an exception occurs on element 0, the trap is taken without modifying vl; however, exceptions on subsequent elements reduce vl to the index of the faulting element without taking a trap. For interrupts, vl remains unchanged and vstart is set, while debug data-watchpoint traps on elements after the first trigger the trap without reducing vl. If vstart is 0 and vl is greater than 0, the instruction must process at least one element.
