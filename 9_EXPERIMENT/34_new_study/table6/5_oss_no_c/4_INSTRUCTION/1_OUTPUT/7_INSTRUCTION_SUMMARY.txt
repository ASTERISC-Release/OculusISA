INSTRUCTION: CSRRWI
SUMMARY: CSRRWI writes the targeted CSR with an XLEN‑bit value formed by zero‑extending the 5‑bit immediate in the rs1 field, affecting all writable fields and their defined side‑effects. If rd ≠ x0, the instruction atomically reads the CSR, zero‑extends the old value to XLEN, and writes it to rd; if rd = x0, the CSR is written but no read or read‑side‑effects occur. The operation is subject to the normal privilege and access‑control checks for CSR writes. The instruction performs an atomic read‑modify‑write, or a write‑only when rd = x0.

INSTRUCTION: SFENCE.VMA
SUMMARY: SFENCE.VMA is a supervisor fence that flushes address‑translation structures; its encoding fixes funct3 to 000 and rd to x0, and rs1 optionally supplies a virtual address, which if invalid makes the instruction a no‑op. Execution is allowed only in S‑mode when mstatus.TVM=0; otherwise an illegal‑instruction exception is raised, while any use in U‑mode is illegal and in VS/VU modes a virtual‑instruction trap (exception code 22) is taken when hstatus.VTVM=1 or privilege is insufficient. The instruction follows the same permission checks and exception behavior as SINVAL.VMA, and virtual‑instruction traps write mtval/stval with the same value as an illegal‑instruction trap. No other exceptions are generated.

INSTRUCTION: VLE32FF.V
SUMMARY: VLE32FF.V is a 32‑bit element vector load that uses the architectural vector length register (vl) to bound the number of elements fetched and the vector‑start register (vstart) to record the current element index. A synchronous exception on element 0 causes an immediate trap without modifying vl, whereas an exception on any later element does not trap and instead truncates vl to that element's index. If an interrupt or a debug data‑watchpoint occurs on an element beyond the first, vl is left unchanged and vstart (or the debug trap) is updated so execution can resume correctly. The instruction obeys the normal load privilege checks and requires no special access permissions.
