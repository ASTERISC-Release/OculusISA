INSTRUCTION: CSRRWI
SUMMARY: CSRRWI writes the addressed CSR with the zero‑extended 5‑bit immediate and may read the previous CSR value into integer register rd. When rd ≠ x0 the instruction atomically reads the CSR (placing the old value in rd) and writes the immediate; when rd = x0 the read is omitted and no read side‑effects occur. The CSR operand is always a destination (the write target), while rd is a destination register only if it is not x0 (otherwise it is unused). The CSR write always happens—even for an immediate of zero—triggering any defined side effects and subject to the privilege level required to access that CSR.

INSTRUCTION: FCVT.W.D
SUMMARY: FCVT.W.D reads a double‑precision floating‑point value from source floating‑point register rs1, converts it to a signed 32‑bit integer using the rounding mode given by the rm field, and writes the sign‑extended result into integer register rd. The conversion follows the same range and invalid‑input handling as the single‑precision FCVT.int.S operation and raises the standard floating‑point exception flags (invalid, overflow, underflow, inexact, etc.) appropriate to the rounding. The instruction is defined only when the D (double‑precision) extension is implemented; otherwise it traps as an illegal instruction. No modulo‑2³² reduction is performed—the result is a normal sign‑extended integer.

INSTRUCTION: SFENCE.VMA
SUMMARY: SFENCE.VMA synchronizes supervisor address‑translation structures, using rs1 to supply a virtual address (or x0 for no address) and rs2 to supply an address‑space identifier (bits above the architectural ASID limit are ignored and over‑fencing by treating any subset of bits as zero is always permitted). The instruction is only defined for supervisor privilege; it raises an illegal‑instruction exception in U‑mode, VU‑mode, and in any mode where the corresponding trap‑enable bit is set. The mstatus.TVM bit (for S‑mode) and the hstatus.VTVM bit (for VS‑mode) control trapping: TVM = 1 causes an illegal‑instruction exception in S‑mode, while VTVM = 1 causes a virtual‑instruction exception (code 22) in VS‑mode, which the hypervisor may convert to an illegal‑instruction exception if not emulated. If rs1 does not contain a valid virtual address the instruction has no effect and raises no exception.

INSTRUCTION: VLE32FF.V
SUMMARY: VLE32FF.V is a 32‑bit unit‑stride fault‑only‑first vector load that reads elements from the memory address in rs1 into the destination vector register vd, optionally gated by mask vm. If the first element causes a synchronous exception the instruction traps and leaves the current vl unchanged, whereas a fault on any later element silently reduces vl to the index of that element and leaves subsequent destination elements indeterminate while preserving elements beyond the original vl. Implementations may process fewer than the programmed number of elements but must load at least one element when vstart = 0 and vl > 0, and they must not reduce vl for interrupt or debug‑watchpoint traps, instead using vstart to resume execution. Encoding a fault‑only‑first load in a non‑unit‑stride form (constant‑stride or scatter/gather) raises an illegal‑instruction exception.
