INSTRUCTION: CSRRWI
SUMMARY: The CSRRWI instruction atomically updates a specified CSR with a zero-extended 5-bit unsigned immediate value and writes the CSR's original value to destination register rd. If rd is x0, the instruction skips reading the CSR and avoids any associated read-side effects. The CSR is always written to, triggering all defined architectural side effects for that CSR. When rd is any register other than x0, it serves as the destination for the updated value.

INSTRUCTION: FCVT.W.D
SUMMARY: FCVT.W.D converts a double-precision floating-point number from register rs1 to a signed 32-bit integer in register rd, rounding the result according to the rm field. In RV64, the 32-bit result is sign-extended. If the input is outside the valid range or is invalid as defined for FCVT.int.S, the destination register receives the same result as FCVT.int.S.

INSTRUCTION: SFENCE.VMA
SUMMARY: SFENCE.VMA uses the value in rs1 as a virtual address, having no effect if the address is invalid. Execution in S-mode is permitted only when TVM=0, otherwise it raises an illegal-instruction exception. Execution in U-mode always raises an illegal-instruction exception. Attempts to execute the instruction in VS-mode or VU-mode raise virtual-instruction exceptions, specifically when VTVM=1 or hstatus.VTVM=1.

INSTRUCTION: VLE32FF.V
SUMMARY: VLE32FF.V must process at least one element if vstart is 0 and vl is greater than 0. Synchronous exceptions on element 0 trigger a trap without modifying vl, while exceptions on subsequent elements reduce vl to the index of the faulting element without taking a trap. Interrupts should not reduce vl but instead set a vstart value. Debug data-watchpoint traps on elements after the first should trigger the trap without reducing vl.
