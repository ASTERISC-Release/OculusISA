REGISTER: mseccfg
SUMMARY: The mseccfg register, located at address 0x747 with MRW privilege, manages security configurations including seed CSR access, PMP behavior, pointer masking, and M-mode Zicfilp enablement. The SSEED and USEED fields control seed CSR access for S/HS-mode and U-mode respectively, where a value of 0 triggers illegal-instruction exceptions. The MML, MMWP, and RLB fields modify PMP rule semantics, such as defining M-mode-only or Shared-Regions and controlling rule locking and default M-mode memory policies. Additionally, the PMM field configures pointer masking lengths, while the MLPE field determines Zicfilp extension enablement and xLPE state for M-mode.

REGISTER: mstatus
SUMMARY: The mstatus register tracks processor state, including privilege modes, interrupt enables, and the status of floating-point, vector, and other user-mode extensions (FS, VS, XS, SD). It manages trap transitions by saving previous privilege and interrupt states (xPP, xPIE) and controls memory access behaviors through fields like MPRV, SUM, and endianness settings (MBE, SBE, UBE). Certain fields are restricted, such as CSR access at 0x300 from levels below Machine mode, while writes beyond MXLEN are ignored. Many instructions, particularly those involving vector or floating-point state when disabled (Off), or SRET when TSR is set, will trigger illegal-instruction exceptions.

REGISTER: satp
SUMMARY: The satp register manages address translation by storing the root page table's physical page number (PPN), the translation mode (MODE), and the address space identifier (ASID). Access is restricted to Supervisor privilege levels or higher, though S-mode access is prohibited when TVM=1. The MODE field determines the translation scheme (such as Bare or various Sv page-based addressing modes), with certain configurations restricted by SXLEN. Invalid or unsupported MODE values and invalid PPNs typically trigger illegal-instruction, page-fault, or access-fault exceptions.

REGISTER: scounteren
SUMMARY: The scounteren register controls U-mode access to the cycle, time, instret, and hpmcountern counters via the CY, TM, IR, and HPM n bits respectively. Access to these counters is permitted in U-mode only when the corresponding bit in both scounteren and mcounteren is set. If a corresponding bit in scounteren is clear, attempting to read the associated counter in U-mode triggers an illegal-instruction exception. Additionally, accessing the scounteren register itself from a privilege level lower than Supervisor raises an illegal-instruction exception.
