INSTRUCTION: CSRRWI
SUMMARY: CSRRWI unconditionally writes the selected CSR with the XLEN-bit zero-extension of the 5-bit unsigned immediate, including when the immediate is zero. If rd is nonzero, the CSR read and write occur atomically, and rd receives the CSR's zero-extended pre-instruction value; if rd is x0, no CSR read or read side effects occur. Defined CSR write side effects still occur, and the explicit write replaces any update that would otherwise result from instruction-execution side effects.

INSTRUCTION: FCVT.W.D
SUMMARY: FCVT.W.D converts the double-precision value in floating-point register rs1 to a signed 32-bit integer in integer register rd, using the rounding mode specified by rm; on RV64, the result is sign-extended. It has the same valid input range and invalid-input behavior as FCVT.W.S, setting fflags.NV for out-of-range inputs. For the same operand, it raises the same floating-point exception flags as FCVTMOD.W.D.

INSTRUCTION: SFENCE.VMA
SUMMARY: SFENCE.VMA uses rs1 as a virtual-address operand; for an otherwise permitted execution, an invalid address has no effect and raises no exception. Execution in U-mode is illegal, while S-mode and HS-mode execution is illegal when mstatus.TVM is set; S-mode execution is permitted when TVM is clear. VU-mode execution raises a virtual-instruction exception, and VS-mode does so when hstatus.VTVM is set; VTVM applies only to VS-mode, where mstatus.TVM and mstatus.TSR are ignored. SFENCE.VMA has the same exception behavior and cause as SINVAL.VMA, and virtual-instruction traps write mtval or stval as corresponding illegal-instruction traps would.

INSTRUCTION: VLE32FF.V
SUMMARY: VLE32FF.V performs a unit-stride vector load of 32-bit memory elements. A synchronous exception on element 0 traps and leaves vl unchanged, while an exception on a later element is suppressed and sets vl to that element's index. If execution starts with vstart = 0 and vl > 0 and no exception occurs, at least one element is processed.
