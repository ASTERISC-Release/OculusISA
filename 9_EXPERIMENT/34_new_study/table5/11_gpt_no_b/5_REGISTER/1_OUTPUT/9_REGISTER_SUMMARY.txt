REGISTER: mseccfg
SUMMARY: mseccfg is an M-mode read/write security-configuration CSR; lower-privilege accesses raise illegal-instruction exceptions, and M-mode reads succeed when an implemented extension defines any field. SSEED and USEED gate S/HS-mode and U-mode seed-CSR access, respectively: only read-write accesses are allowed when enabled, while disabled accesses and reads without writes are illegal; M-mode read-write access is always allowed. RLB enables modification of locked PMP entries, while sticky MMWP denies unmatched M-mode memory accesses and sticky MML reinterprets PMP entries as M-only, S/U-only, or shared regions, with permission violations causing access faults and M-mode execution requiring an appropriate executable rule. MLPE controls M-mode Zicfilp landing-pad enforcement and raises software-check exceptions on enabled violations, while PMM is read-only zero if Smmpm is absent.

REGISTER: mstatus
SUMMARY: mstatus is the M-mode read/write status and control CSR, holding privilege, interrupt, trap-return, execution-width, memory-access, virtualization, and extension-state information; direct access below M-mode raises an illegal-instruction exception, while sstatus exposes selected shared state. The interrupt-enable, previous-interrupt-enable, previous-privilege, virtualization, and landing-pad fields capture pre-trap state and control restoration by trap-return instructions. FS, VS, and XS summarize floating-point, vector, and other extension state as Off, Initial, Clean, or Dirty, with SD indicating any Dirty state; using disabled state traps, while modifying enabled state generally marks it Dirty, including corresponding guest state when virtualization is active. Other controls select effective XLEN, data-access privilege, virtualization context, and endianness, and can cause supervisor translation or fence operations, SRET, lower-privilege WFI, and vector or vector floating-point operations to raise illegal-instruction exceptions under specified disabled or restricted conditions.

REGISTER: satp
SUMMARY: satp selects the supervisor address-translation mode and identifies the address space through its ASID field. It is supervisor read/write; in S-mode, TVM=1 causes reads and writes to raise an illegal-instruction exception, while TVM=0 permits them. MODE supports Bare and, for SXLEN=64, Sv39, Sv48, and Sv57; unsupported MODE writes are ignored entirely, and a read-only-zero MODE forces Bare mode and makes SUM read-only zero. Implemented ASID bits are writable, contiguous from the least-significant bit, discoverable by write/read probing, and limited to at most 16 bits in the supported paged modes.

REGISTER: scounteren
SUMMARY: scounteren is a mandatory CSR that controls U-mode access to the cycle, time, instret, and hardware performance-monitoring counters. U-mode reads or writes of scounteren raise an illegal-instruction exception, while S-mode and M-mode may access it. A U-mode counter read is permitted only when the corresponding scounteren and mcounteren bits are both set; otherwise, including for read-only-zero scounteren bits, it raises an illegal-instruction exception. mcounteren settings do not affect whether scounteren bits are writable.
