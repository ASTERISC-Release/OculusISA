REGISTER: mseccfg
SUMMARY: The mseccfg register is a Machine-mode register that configures seed CSR access, PMP behavior, pointer masking, and Zicfilp enablement. The SSEED and USEED fields control seed CSR access for S-mode and U-mode respectively, while RLB, MMWP, and MML modify PMP rule locking, default M-mode policies, and memory region designations. Access to mseccfg from any privilege level lower than Machine mode raises an illegal-instruction exception. Specific fields such as MMWP, MML, and PMM may be sticky or read-only depending on implementation and system state.

REGISTER: mstatus
SUMMARY: The mstatus register manages processor state, including interrupt enables, privilege levels, and extension statuses for floating-point (FS), vector (VS), and other user-mode extensions (XS). It controls memory access behavior via fields such as MPRV, SUM, and endianness settings (MBE, SBE, UBE), while tracking trap-related state through fields like xPIE and xPP. Access is restricted to Machine mode; attempts to read or write mstatus from lower privilege modes raise an illegal-instruction exception. Specific configurations of FS, VS, or TVM can trigger illegal-instruction exceptions when attempting to execute corresponding floating-point, vector, or memory-management instructions.

REGISTER: satp
SUMMARY: The satp register manages virtual address translation by storing the root page table's physical page number (PPN), the address space identifier (ASID), and the translation MODE. Access is generally restricted to Supervisor mode or higher, raising an illegal-instruction exception if accessed from U-mode or when TVM=1 in S-mode. The MODE field determines the translation scheme (e.g., Bare, Sv39, Sv48, Sv57), where Bare mode equates virtual and physical addresses and causes shadow stack instructions to fault in modes below M. Writes with unsupported MODE values are ignored, and specific privilege restrictions apply to field modifications, such as the SUM field being read-only 0 when MODE is read-only 0.

REGISTER: scounteren
SUMMARY: The scounteren register controls U-mode access to various counters, including cycle (CY), time (TM), instret (IR), and hpmcountern (HPM n) registers. U-mode may only access a counter if the corresponding bits in both scounteren and mcounteren are set; otherwise, an illegal-instruction exception is raised. Reading or writing scounteren requires Supervisor privilege or higher, with attempts from lower privilege modes causing an illegal-instruction exception. Access to the register is permitted in M-mode and HS-mode without exception, and writes to its fields are reflected upon readback.
