INSTRUCTION: CSRRWI
SUMMARY: The CSRRWI instruction updates a specified CSR with a zero-extended 5-bit unsigned immediate. If the destination register rd is not x0, the original value of the CSR is read and written to rd; otherwise, no read occurs and no read-related side effects are triggered. The CSR is always updated regardless of the rd or immediate values. The CSRWI pseudoinstruction is implemented as CSRRWI with rd set to x0.

INSTRUCTION: FCVT.W.D
SUMMARY: FCVT.W.D converts a double-precision floating-point number from register rs1 to a signed 32-bit integer in register rd, rounding according to the rm field. In RV64, the resulting 32-bit integer is sign-extended. If the input is outside the representable signed 32-bit integer range, the result matches that of FCVT.int.S. Floating-point exception flags are raised based on the input operand.

INSTRUCTION: SFENCE.VMA
SUMMARY: The SFENCE.VMA instruction has no effect if rs1 contains an invalid virtual address and does not utilize pointer masking. It must have an rd field of 00000 to avoid an illegal-instruction exception. Executing the instruction in S-mode while the TVM bit is set, or in VS-mode while hstatus.VTVM is set, raises an illegal-instruction or virtual-instruction exception, respectively.

INSTRUCTION: VLE32FF.V
SUMMARY: VLE32FF.V processes vector elements, requiring at least one element be processed or vl be modified if vstart is 0 and vl > 0. Synchronous exceptions on element 0 trigger a trap without modifying vl, while exceptions on subsequent elements reduce vl to the index of the faulting element. Interrupts are handled by setting vstart instead of reducing vl. Debug data-watchpoint traps on any element after the first trigger a trap without reducing vl.
