REGISTER: mseccfg
SUMMARY: The mseccfg register (address 0x747) manages security boundaries and machine-mode configurations, including seed CSR access control (SSEED, USEED), PMP policies (RLB, MMWP, MML), pointer masking (PMM), and landing pad checks (MLPE). Access is restricted to Machine mode, with attempts from lower privilege levels raising an illegal-instruction exception; furthermore, accessing the register requires the Zkr extension to be implemented. SSEED and USEED fields control whether S-mode or U-mode can access seed CSRs, otherwise raising an illegal-instruction exception. Depending on implementation, fields like RLB, MMWP, and MML may be WARL or sticky, controlling PMP rule modifications and memory access exceptions.

REGISTER: mstatus
SUMMARY: The mstatus register tracks the processor's current state, including interrupt enables, privilege modes, and the status of floating-point, vector, and other user-mode extensions (FS, VS, XS) to optimize context switching. It manages memory access behaviors via fields such as MPRV, MXR, and SUM, while controlling endianness through MBE, SBE, and UBE. Access is restricted to Machine mode, with attempts from lower privilege levels raising an illegal-instruction exception. Notable exception behaviors include illegal-instruction faults when executing instructions for extensions set to Off or when executing SRET while the TSR bit is set.

REGISTER: satp
SUMMARY: The satp register controls address translation for supervisor-mode and user-mode memory accesses, using fields for the translation MODE, Address Space Identifier (ASID), and Physical Page Number (PPN) of the root page table. Access is restricted to Supervisor mode or higher, and any attempt to read or write the register from a lower privilege level, or while the mstatus.TVM bit is set in S-mode, triggers an illegal-instruction exception. In SXLEN=64, setting MODE to Bare is prohibited, and unsupported MODE values result in writes being ignored or memory access exceptions. Invalid CSR addresses for satp or writes that violate specific privilege and mode constraints will raise an illegal-instruction exception.

REGISTER: scounteren
SUMMARY: The scounteren register (address 0x106) controls U-mode access to the cycle, time, instret, and hpmcounter registers. U-mode access to a counter is permitted only if the corresponding enable bit in both scounteren and mcounteren is set; otherwise, an illegal-instruction exception is raised. The register is accessible in M-mode and HS-mode without exception, but any access attempt from U-mode or via VS-extension CSRs triggers an illegal-instruction exception. When V=1, the register must maintain its standard read/write behavior to ensure correct counter enabling and readback values.
