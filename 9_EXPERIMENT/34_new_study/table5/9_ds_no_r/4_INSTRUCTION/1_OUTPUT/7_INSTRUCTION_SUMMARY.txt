INSTRUCTION: CSRRWI
SUMMARY: CSRRWI atomically reads and writes the single CSR selected by the csr field, writing the zero-extended 5-bit unsigned immediate encoded in the rs1 field; the uimm=0 no-write condition does not apply to CSRRWI. When rd is nonzero, the destination register receives the zero-extended pre-write CSR value and any architecturally defined CSR read side effects occur; when rd is x0, no CSR read or read side effect occurs, no destination is written, and x0 remains zero. The CSR write has the same architectural side effects as a CSRRW write to that CSR. If the selected CSR is read-only, CSRRWI raises an illegal-instruction exception.

INSTRUCTION: FCVT.W.D
SUMMARY: FCVT.W.D reads a double-precision floating-point value from floating-point register rs1, rounds it according to rm, and writes a signed 32-bit integer to integer register rd (sign-extended to XLEN on RV64). The provided rules do not state any access-control or privilege restrictions. For NaN or a rounded value outside [-2^31, 2^31-1], it writes the same invalid-input result as FCVT.W.S: 0 for NaN, 0x7fffffff for positive overflow, or 0x80000000 for negative overflow (sign-extended on RV64), sets fflags.NV, and raises no illegal-instruction exception. A rounded result within range is written to rd without setting fflags.NV.

INSTRUCTION: SFENCE.VMA
SUMMARY: SFENCE.VMA is a supervisor virtual-memory management operation controlled by TVM: in S-mode, TVM=1 raises an illegal-instruction exception while TVM=0 permits execution. Under virtualization, hstatus.VTVM=1 causes VS-mode attempts (and relevant VU-mode supervisor-SFENCE attempts) to raise a virtual-instruction exception with cause 22, writing mtval/stval as for an illegal-instruction trap, while mstatus.TSR/TVM are ignored for VS-mode determination. An invalid rs1 virtual-address value raises no exception and produces no architectural effect or state change attributable to SFENCE.VMA. Virtual-instruction traps have priority below illegal instruction and above instruction address misaligned, and if a hypervisor does not emulate a guest SFENCE.VMA virtual-instruction trap, the guest observes an illegal-instruction exception instead.

INSTRUCTION: VLE32FF.V
SUMMARY: VLE32FF.V performs a 32-bit unit-stride fault-only-first vector load, writing successfully loaded elements to vd and using vl plus vstart to report progress and the first uncompleted element. A synchronous exception on element 0 is trapped with vl unchanged, while a synchronous exception on an element after 0 is not trapped and vl is reduced to that element's index. Even without an exception the implementation may process fewer than vl elements and reduce vl, but if vstart = 0 and vl > 0 at least one element must be processed; on an interrupt, vl retains its pre-instruction value and vstart is set to the first vector element not completed. A debug data-watchpoint trap on an element after the first should be triggered without reducing vl, and the rules specify no additional access-control or privilege restrictions.
