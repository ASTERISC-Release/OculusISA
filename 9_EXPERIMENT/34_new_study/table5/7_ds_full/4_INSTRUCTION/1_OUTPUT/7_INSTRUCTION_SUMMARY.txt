INSTRUCTION: CSRRWI
SUMMARY: CSRRWI atomically operates on the selected CSR: when rd is not x0, it reads that CSR, writes the zero-extended 5-bit unsigned immediate into the CSR, and places the previously read CSR value in rd, with no other CSR changed. The CSR write must perform all defined write side effects, and reads when rd is not x0 also cause the CSR's defined read side effects. When rd is x0, the CSR is not read and no read side effects or read-related exceptions occur, but the specified CSR write still occurs and x0 remains zero. A writable CSR is updated by the immediate; a read-only or otherwise illegal write raises an illegal-instruction exception with no CSR write or write side effect.

INSTRUCTION: FCVT.W.D
SUMMARY: FCVT.W.D converts a double-precision floating-point value in floating-point register rs1 to a signed 32-bit integer in integer register rd, rounding according to the rm field. On RV64, the 32-bit result is sign-extended into the destination integer register. Invalid inputs, including NaN, infinity, or finite values that round outside the signed 32-bit integer range, set fflags.NV and write the saturated signed 32-bit result (0x7fffffff for NaN/positive overflow/+infinity; 0x80000000 for negative overflow/-infinity), matching what FCVT.W.S writes for that invalid input, without raising an illegal-instruction exception; for a given operand, it raises the same floating-point exception flags as FCVTMOD.W.D. The provided rules state no privilege or access-control restrictions.

INSTRUCTION: SFENCE.VMA
SUMMARY: SFENCE.VMA requires the same permissions and raises the same exceptions as SINVAL.VMA, and an invalid virtual address in rs1 raises no exception. Execution is permitted in S-mode only when mstatus.TVM=0; with TVM=1 in S-mode or HS-mode it raises an illegal-instruction exception, and execution in U-mode always raises an illegal-instruction exception. In virtualized modes, execution in VU-mode raises a virtual-instruction exception, and in VS-mode with hstatus.VTVM=1 it raises a virtual-instruction exception (code 22 when V=1), with mtval or stval written as for an illegal-instruction trap.

INSTRUCTION: VLE32FF.V
SUMMARY: VLE32FF.V is a regular vector load with fault-only-first trimming, using vl and vstart to track vector length and progress. A synchronous exception on element 0 traps without changing vl, while an exception on a later element is not taken and reduces vl to that element's index; active destination elements may still update past the trim point but not past the original vl. Restartable loads must not re-access non-idempotent locations if doing so would repeat observable read side effects, and an interrupt trap leaves vl unchanged with vstart set to the first uncompleted element. A debug data-watchpoint after the first element should trigger the debug trap without reducing vl, and when no exception occurs with vstart=0 and vl>0, at least one element must be processed; no access-control or privilege restrictions are stated.
