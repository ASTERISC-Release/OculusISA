INSTRUCTION: CSRRWI
SUMMARY: CSRRWI treats uimm as a zero-extended 5-bit immediate, not a GPR index, and writes its XLEN-bit value to the addressed CSR. If rd is not x0, the CSR's pre-update value is read, zero-extended to XLEN, and written to rd; if rd is x0, the CSR is not read and no CSR-read side effects occur. The CSR write is always attempted, even when uimm is zero, so write side effects still occur and an attempted write to a read-only CSR can raise an illegal-instruction exception. An explicit CSRRWI write takes precedence over any update that would otherwise occur as an instruction side effect.

INSTRUCTION: FCVT.W.D
SUMMARY: FCVT.W.D converts a double-precision floating-point operand to a signed 32-bit integer and writes it directly to integer register rd, using the rounding mode selected by rm. It is supported with XLEN of 32 or 64, and on RV64 the result is sign-extended to XLEN. Invalid inputs or rounded results outside the signed 32-bit range set fflags.NV and produce the architecturally defined clipped invalid-conversion result; NaN and infinity do not produce zero, and no exception is raised merely because rm is not round-toward-zero.

INSTRUCTION: SFENCE.VMA
SUMMARY: SFENCE.VMA uses rs1 to select a virtual address and rs2 to select an ASID; an invalid rs1 address makes the instruction a no-op without exception, while unsupported high ASID bits in rs2 are ignored. Execution in U-mode is illegal, and execution in S-mode or HS-mode is illegal when mstatus.TVM=1. In VU-mode it raises a virtual-instruction exception, while in VS-mode this occurs only when hstatus.VTVM=1; mstatus.TVM and mstatus.TSR do not affect VS-mode execution. A virtual-instruction exception has code 22 and records trap information like an illegal-instruction exception, with illegal-instruction taking priority if both exceptions qualify.

INSTRUCTION: VLE32FF.V
SUMMARY: VLE32FF.V loads active destination vector elements with 32-bit values from base + 4*i and otherwise behaves like VLE32.V except for fault-only-first handling. A synchronous exception on element 0 traps without changing vl, while a fault on any later element is suppressed and trims vl to that element's index. After such trimming, originally active destination elements beyond the fault may contain arbitrary values, with updates constrained by the original vl. An interrupt leaves vl unchanged and sets vstart to the resumable element index; when vstart is zero and vl is nonzero, at least one element is processed.
