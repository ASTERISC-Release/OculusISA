INSTRUCTION: CSRRWI
SUMMARY: CSRRWI writes the single CSR selected by its CSR specifier with a zero-extended 5-bit unsigned immediate instead of an integer register value. With rd not equal to x0, it also reads that CSR and any architectural side effects of the read occur; with rd = x0, it only performs the CSR write and read-only side effects or read-caused exceptions do not occur. A successful CSRRWI write changes architectural state exactly as writing the immediate to that CSR, including all defined per-field write side effects, and rd = x0 is observable only through the CSR write or a CSR write-access exception. No additional privilege or access-control restrictions are stated in the provided rules.

INSTRUCTION: FCVT.W.D
SUMMARY: FCVT.W.D converts the double-precision value in floating-point register rs1 to a signed 32-bit integer in integer register rd, rounds according to rm (with non-RTZ rounding able to differ from truncation), and on RV64 sign-extends the 32-bit result to XLEN. It sets NX for non-exact conversions and NV for NaN, infinity, or an out-of-range signed 32-bit result; positive overflow or positive infinity produces 0x7fffffff sign-extended, while negative overflow produces 0x80000000 sign-extended. With invalid-operation exceptions enabled, a positive-infinity source raises instead of writing the destination, and negative infinity or NaN are not converted to zero. No privilege or access-control restrictions are specified in the provided rules.

INSTRUCTION: SFENCE.VMA
SUMMARY: SFENCE.VMA uses rs1 as a virtual-address operand and rs2 for ASID-related bits, requires the same permissions as SINVAL.VMA, raises no exception for an invalid rs1 value, and ignores reserved ASID bits in rs2 while translations behave as if those bits were zero and defined ASID bits remain unchanged. In S-mode, execution is permitted when mstatus.TVM=0 but raises an illegal-instruction exception when TVM=1; U-mode attempts always raise an illegal-instruction exception, and HS-mode with mstatus.TVM=1 also raises an illegal-instruction exception. VU-mode execution raises a virtual-instruction exception, and VS-mode execution with hstatus.VTVM=1 raises a virtual-instruction exception rather than an illegal-instruction exception, while hstatus.VTVM has no effect outside VS-mode. For such VS-mode VTVM traps, mtval or stval is written the same as for an illegal-instruction trap.

INSTRUCTION: VLE32FF.V
SUMMARY: The provided rules do not specify a register purpose, privilege level, or access-control restrictions for VLE32FF.V. For synchronous faults, an exception on element 0 causes VLE32FF.V to take the trap and leave vl unchanged, while an exception on a later element does not cause that trap and instead reduces vl to the faulting element's index. If vstart equals 0 and vl is greater than 0, at least one element must be processed, and active destination elements past the original vector length must not be updated. Interrupt traps and debug data-watchpoint traps on elements after the first must not reduce vl.
