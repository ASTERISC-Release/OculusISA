## 5.7.6. Trigger Control (tcontrol, at 0x7a5)

This optional register is only accessible in M-mode and Debug Mode and provides various control bits related to triggers.

This CSR is read/write.

<image>

| Field   | Description                                                                                                                                                                                                                                                                                     | Access   |   Reset |
|---------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------|---------|
| mpte    | M-mode previous trigger enable field. mpte and mte provide one solution to a problem regarding triggers with action=0 firing in M-mode trap handlers. See Section 5.4 for more details. When any trap into M-mode is taken, mpte is set to the value of mte.                                    | WARL     |       0 |
| mte     | M-mode trigger enable field. 0 (disabled): Triggers with action=0 do not match/fire while the hart is in M-mode. 1 (enabled): Triggers do match/fire while the hart is in M- mode. When any trap into M-mode is taken, mte is set to 0. When mret is executed, mte is set to the value of mpte. | WARL     |       0 |
