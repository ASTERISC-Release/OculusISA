## 5.7.8. Supervisor Context (scontext, at 0x5a8)

This optional register is only accessible in S/HS-mode, VS-mode, M-mode and Debug Mode.

Accessibility of this CSR is controlled by mstateenzero[57] and hstateenzero[57] in the Smstateen extension. Enabling scontext can be a security risk in a virtualized system with a hypervisor that does not swap scontext.

This CSR is read/write.

| XLEN-1 32 31   | 0    |
|----------------|------|
| 0              | data |
| XLEN - 32      | 32   |

| Field   | Description                                                                                                                                                                                                                                                                               | Access   |   Reset |
|---------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------|---------|
| data    | Supervisor mode software can write a context number to this register, which can be used to set triggers that only fire in that specific context. An implementation may tie any number of high bits in this field to 0. It's recommended to implement 16 bits on RV32 and 32 bits on RV64. | WARL     |       0 |
