## 4.7. Halt

When a hart halts:

1. cause is updated.
2. prv and v are set to reflect current privilege mode and virtualization mode.
3. If  the  Zicfilp  extension  is  implemented,  pelp  is  set  to  the  current ELP state  and ELP is  set  to NO\_LP\_EXPECTED

4. dpc is set to the next instruction that should be executed.
5. If the current instruction can be partially executed and should be restarted to complete, then the relevant state for that is updated. E.g. if a halt occurs during a partially executed vector instruction, then vstart is  updated,  and  dpc  is  updated  to  the  address  of  the  partially  executed  instruction. This is analogous to how vector instructions behave for exceptions.
6. The hart enters Debug Mode.
