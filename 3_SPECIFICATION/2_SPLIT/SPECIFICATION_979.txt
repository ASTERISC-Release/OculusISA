## 4.5.16. Interrupt targets ( target[1]-target[1023] )

If  interrupt  source is  inactive  in  this  domain,  register target[ ] is  read-only  zero.  If  source is active, target[ ] determines the hart to which interrupts from the source are signaled or forwarded. The  exact  interpretation  of target[ ] depends  on  the  delivery  mode  configured  by  field  DM  of register domaincfg . 1 1

If domaincfg .DM is changed, the target registers for all active interrupt sources within the domain obtain UNSPECIFIED values in all fields defined for the new delivery mode.
